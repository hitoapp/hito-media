# 素材说明

## 当前素材

本目录用于保存喜多渠道二维码功能公众号内容素材。当前已按新版本补充 HTML 设计稿：

```text
publish/official-account/2026-06-26-渠道二维码/文案.html
```

该 HTML 来源于 `hito-mp/docs/渠道码/channel-code-ticket-design.html`，用于展示渠道码票根设计稿。

图片目录：

```text
publish/official-account/2026-06-26-渠道二维码/生成配图/
```

## 正文配图

0. `hito-head-logo.png`
   - 来源：`hito-mp/src/images/hito-head-logo.png`。
   - 用途：供 `文案.html` 中票根底部品牌 logo 使用。

1. `创建多个渠道的渠道码.PNG`
   - 来源：用户提供截图。
   - 用途：展示同一活动可创建多个渠道，例如第三方广告推广、微信会员群、小红书推广、微信活动公共群。
   - 建议插入位置：正文“在喜多中创建不同渠道”小节。

2. `渠道码示例.PNG`
   - 来源：用户提供截图。
   - 用途：展示单个渠道二维码的样式，以及渠道名称、活动名称、活动时间等信息。
   - 建议插入位置：说明“每个渠道都可以生成独立二维码”之后。

## 封面建议

- 封面比例：公众号大图封面建议 900 x 383。
- 封面文字：渠道码上线。
- 画面方向：活动二维码 + 多渠道来源标签，例如“小红书 / 微信群 / 线下海报 / 合作方”。
- 如果使用现有截图做封面，建议基于 `渠道码示例.PNG` 裁切重排，不直接使用竖版原图。

## 发布前检查

- 预览 `文案.html` 时，确认底部 logo 能正常显示。
- 检查截图中的头像、昵称、活动名称、活动时间是否可以公开展示。
- 如果活动信息只是示例，可保留；如涉及真实未公开活动，建议打码或替换。
- 竖版截图插入公众号正文时，建议控制宽度，不要连续堆图。

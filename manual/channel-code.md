# 渠道码系统

## 概述

渠道码系统是喜多活动推广与数据归因的核心工具。它允许管理员为同一个活动创建多个独立的推广入口（即"渠道"），并为每个渠道生成专属的二维码。用户扫码进入活动后，系统自动记录扫码来源，帮助管理员统计不同推广渠道的参与效果。

渠道码适用于微信群、小红书、海报、线下物料等各类推广场景。每个渠道码拥有独立的浏览量和扫码人数统计，管理员可以清晰地了解每个渠道的引流表现。

本功能面向群组主理人和群组管理员，支持渠道的创建、编辑、删除、启用/停用，以及渠道码的生成、查看和下载。

## 核心概念

- **渠道**：推广来源的命名分组，例如"微信群渠道""小红书渠道"等。每个渠道属于一个群组，可跨多个活动复用。
- **渠道码**：针对某个渠道在特定活动下生成的专属二维码。扫码后系统自动记录来源渠道，实现推广归因。
- **渠道码编码**：系统为每张渠道码生成的唯一编码，嵌入二维码中，用户扫码时自动传递给系统。
- **渠道管理**：群组维度的渠道维护功能，支持创建、编辑、删除和启用/停用渠道。
- **渠道码详情**：单张渠道码的数据看板，展示浏览量、扫码去重人数和扫码用户列表。

## 操作指南

### 场景：进入渠道码页面

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可查看全部渠道及渠道码 |
| 群组管理员 | ✓ | 可查看全部渠道及渠道码 |

#### 操作入口

活动详情页 → 右上角管理菜单 → 渠道码

#### 操作流程

1. 在活动详情页，点击右上角管理菜单中的"渠道码"入口。
2. 系统加载当前活动关联的所有渠道和渠道码列表。
3. 页面顶部显示"二维码已全新升级成渠道码"提示，点击问号图标可查看渠道码说明。
4. 渠道列表按是否已生成渠道码、是否启用等状态排序展示。

#### 限制与约束

- 必须从活动详情页进入，页面需要活动 ID 和群组 ID 参数，缺少任一参数将自动返回上一页。

#### 常见问题

Q: 页面提示"缺少活动或群组参数"怎么办？
A: 请确认从活动详情页正常进入，不要直接通过其他方式打开此页面。

### 场景：进入渠道管理页面

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可查看全部渠道，可执行所有管理操作 |
| 群组管理员 | ✓ | 可查看全部渠道，可编辑自己创建的渠道 |

#### 操作入口

群组首页 → 渠道管理

#### 操作流程

1. 在群组首页，点击"渠道管理"入口。
2. 系统加载当前群组下所有渠道列表。
3. 页面显示渠道名称、备注、状态（已禁用）和操作按钮。
4. 底部有"新增渠道"按钮。

#### 限制与约束

- 必须从群组首页进入，页面需要群组 ID 参数。
- 删除、启用/停用按钮仅群组主理人可见。

#### 常见问题

Q: 页面提示"缺少群组参数"怎么办？
A: 请确认从群组详情页正常进入。

### 场景：创建渠道

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可为群组创建任意渠道 |
| 群组管理员 | ✓ | 可为群组创建渠道 |

#### 操作入口

渠道管理页 → 底部"新增渠道"按钮

或

渠道码页面 → "新增渠道"按钮

#### 操作流程

1. 点击"新增渠道"按钮，弹出创建渠道弹窗。
2. 输入渠道名称（必填，最多 40 个字符）。
3. 输入渠道备注（选填，最多 100 个字符）。
4. 点击"创建"按钮提交。
5. 在渠道管理页创建后，显示"创建成功"提示并刷新列表。
6. 在渠道码页面创建后，系统自动为当前活动生成该渠道的渠道码，并跳转到渠道码详情页。

#### 限制与约束

- 渠道名称为必填项，不能为空。
- 同一群组下渠道名称不可重复（后端校验）。

#### 常见问题

Q: 为什么提示"请输入渠道名称"？
A: 渠道名称是必填项，请输入名称后再提交。

Q: 创建渠道后在哪里可以看到？
A: 在渠道管理页和渠道码页面的渠道列表中均可看到新创建的渠道。

### 场景：编辑渠道

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可编辑任意渠道 |
| 群组管理员 | 仅自己创建的 | 只能编辑自己创建的渠道 |

#### 操作入口

渠道管理页 → 点击渠道卡片上的"编辑"按钮

或

渠道码详情页 → 点击渠道名称旁的编辑图标

#### 操作流程

1. 点击"编辑"按钮，弹出编辑渠道弹窗。
2. 修改渠道名称或备注。
3. 点击"保存"按钮提交。
4. 系统提示"保存成功"并刷新数据。

#### 限制与约束

- 渠道码详情页的编辑图标仅群组主理人可见，群组管理员无法看到编辑入口。

#### 常见问题

Q: 为什么我看不到编辑图标？
A: 渠道码详情页的编辑功能仅群组主理人可用。群组管理员可以在渠道管理页编辑自己创建的渠道。

### 场景：删除渠道

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可删除任意渠道 |
| 群组管理员 | ✗ | 不可执行此操作 |

#### 操作入口

渠道管理页 → 点击渠道卡片上的"删除"按钮

#### 操作流程

1. 点击"删除"按钮，系统弹出确认对话框。
2. 确认对话框显示"删除后不可恢复，确定删除该渠道吗？"。
3. 点击"删除"确认，系统执行删除操作。
4. 系统提示"删除成功"并刷新列表。

#### 限制与约束

- 删除操作不可逆，请谨慎操作。
- 删除渠道后，已关联的渠道码数据将一并清理。

#### 常见问题

Q: 为什么我没有删除按钮？
A: 删除渠道仅群组主理人可以操作，群组管理员没有此权限。

### 场景：启用/停用渠道

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可启用或停用任意渠道 |
| 群组管理员 | ✗ | 不可执行此操作 |

#### 操作入口

渠道管理页 → 点击渠道卡片上的"启用"或"禁用"按钮

#### 操作流程

1. 点击"禁用"按钮（对已启用的渠道），系统弹出确认对话框。
2. 确认后系统执行禁用操作，提示"已禁用"并刷新列表。
3. 点击"启用"按钮（对已禁用的渠道），系统弹出确认对话框。
4. 确认后系统执行启用操作，提示"已启用"并刷新列表。

#### 限制与约束

- 启用/停用按钮仅群组主理人可见。
- 渠道停用后，该渠道的渠道码在渠道码页面显示为"已禁用"状态，用户无法通过该渠道码扫码进入活动。

#### 常见问题

Q: 渠道被禁用后，已生成的渠道码还能用吗？
A: 不能。渠道被禁用后，对应的渠道码显示"已禁用"状态，用户无法通过该渠道码进入活动。

Q: 为什么渠道码页面提示"该渠道已禁用"？
A: 该渠道已被群组主理人停用，请联系群组主理人启用后重试。

### 场景：生成活动渠道码

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可为任意渠道生成渠道码 |
| 群组管理员 | ✓ | 可为任意渠道生成渠道码 |

#### 操作入口

活动详情页 → 渠道码 → 点击渠道卡片上的"点击启用"

#### 操作流程

1. 在渠道码页面的渠道列表中，找到尚未生成渠道码的渠道（右侧显示"点击启用"）。
2. 点击该渠道卡片。
3. 系统自动为该渠道在当前活动下生成渠道码。
4. 提示"启用成功"后自动跳转到渠道码详情页。

#### 限制与约束

- 已停用的渠道无法生成渠道码，点击后会提示"该渠道已禁用"。
- 每个渠道在同一活动下只能生成一个渠道码，重复点击不会创建新的渠道码。

#### 常见问题

Q: 为什么点击渠道后提示"该渠道已禁用"？
A: 该渠道已被禁用，需要先由群组主理人在渠道管理页启用后才能生成渠道码。

### 场景：查看渠道码详情

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可查看全部渠道码详情 |
| 群组管理员 | ✓ | 可查看全部渠道码详情 |

#### 操作入口

渠道码页面 → 点击已生成渠道码的渠道卡片

#### 操作流程

1. 在渠道码页面，点击已生成渠道码的渠道卡片（右侧显示浏览量数字）。
2. 进入渠道码详情页，展示以下信息：
   - 渠道名称和创建人信息
   - 关联的活动名称
   - 创建时间
   - 总浏览数据：浏览人数 / 浏览次数
   - 渠道码二维码
3. 下方展示"渠道用户"列表，可按"已参与""未参与""游客"三类筛选。

#### 限制与约束

- 渠道码详情页默认显示已参与和未参与的用户，不显示游客。可手动切换筛选条件。

#### 常见问题

Q: 渠道用户列表中的"已参与""未参与""游客"怎么区分？
A: "已参与"指已报名或签到的用户；"未参与"指扫码进入但未报名也未签到的用户；"游客"指未登录的扫码用户。

Q: 渠道用户列表怎么加载更多？
A: 向下滚动到底部会自动加载下一页数据。

### 场景：下载渠道码

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可下载任意渠道码 |
| 群组管理员 | ✓ | 可下载任意渠道码 |

#### 操作入口

渠道码详情页 → 二维码下方"下载"按钮

#### 操作流程

1. 在渠道码详情页，点击二维码下方的"下载"按钮。
2. 系统自动生成渠道码海报图片，包含：
   - 渠道码二维码
   - 活动名称
   - 活动时间和地点
   - 渠道名称
   - 喜多品牌标识
3. 生成完成后自动弹出分享面板，可直接分享或保存到相册。
4. 也可以长按二维码图片进行预览和保存。

#### 限制与约束

- 下载功能需要二维码图片加载完成才能使用，未加载完成时会提示"二维码尚未生成完成"。

#### 常见问题

Q: 下载的图片包含哪些内容？
A: 下载的海报图片包含渠道码二维码、活动名称、活动时间、活动地点和渠道名称。

Q: 如何保存到手机相册？
A: 生成海报后会自动弹出分享面板，可以选择保存到相册。也可以长按图片选择保存。

### 场景：用户端渠道码解析

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✓ | 扫码后自动解析渠道来源 |

#### 操作入口

扫描渠道码二维码 → 自动进入活动详情页

#### 操作流程

1. 用户通过微信扫一扫或其他方式扫描渠道码二维码。
2. 系统自动解析渠道码编码，识别推广来源渠道。
3. 用户进入活动详情页，系统记录该次扫码归因到对应渠道。
4. 如果用户是首次扫码，系统将其记录为该渠道的扫码用户。

#### 限制与约束

- 渠道码编码嵌入在二维码中，用户无需手动操作，扫码即自动完成归因。
- 已禁用渠道的渠道码扫码后无法正常进入活动。

#### 常见问题

Q: 扫码后怎么知道自己来自哪个渠道？
A: 扫码归因对用户透明，用户正常参与活动即可。管理员可在渠道码详情页查看各渠道的扫码数据。

Q: 同一个人多次扫码会被重复统计吗？
A: 不会。系统按用户去重统计，同一用户多次扫码只计为一次。

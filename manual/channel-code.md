# 渠道码

## 概述

渠道码是喜多为活动提供的推广追踪工具，可为不同推广渠道生成独立的活动入口二维码。通过渠道码，活动运营者可以清晰了解各渠道（如微信群、小红书、线下海报等）的参与情况和效果数据，实现精细化运营。

渠道码功能主要面向活动运营者和群组管理者，帮助他们创建和管理推广渠道、生成专属二维码、查看扫码数据和用户来源。

## 核心概念

- **渠道**：活动的推广来源分类，如"小红书推广""微信群""线下海报"等，用于区分不同推广途径
- **渠道码**：基于渠道生成的专属活动二维码，用户扫描后系统自动记录其来源渠道
- **群组**：渠道的归属单位，每个群组可独立管理渠道资源
- **渠道用户**：通过扫描渠道码访问活动的用户，系统记录其参与状态

## 操作指南

### 场景：创建和管理渠道

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可创建、编辑、删除、启用/禁用所有渠道 |
| 群组管理员 | ✓（仅自己创建的） | 可创建渠道，可编辑自己创建的渠道名称和备注，不可删除或启禁用 |
| 租户管理员 | ✓ | 可管理所有渠道 |
| 全局管理员 | ✓ | 可管理所有渠道 |

#### 操作入口

活动详情页 → 活动设置 → 渠道管理

#### 操作流程

**创建渠道**

1. 进入渠道管理页面，点击底部「新增渠道」按钮
2. 在弹窗中输入渠道名称（必填），可选填备注说明
3. 点击「创建并启用渠道码」完成创建

**编辑渠道**

1. 点击渠道卡片上的「编辑」按钮
2. 修改渠道名称或备注
3. 点击「保存」完成修改

**禁用/启用渠道**

- 仅群组主理人可操作
- 点击「禁用」按钮，该渠道的渠道码将无法被扫描
- 禁用后按钮变为「启用」，点击可恢复

**删除渠道**

- 仅群组主理人可操作
- 点击「删除」按钮，确认后删除该渠道
- 删除后不可恢复，已生成的渠道码将失效

#### 限制与约束

- 每个群组最多可创建 100 个渠道
- 渠道名称需合理，避免重复
- 禁用渠道后，已生成的渠道码无法正常使用

#### 常见问题

Q: 为什么我无法删除渠道？
A: 仅群组主理人拥有删除渠道的权限，群组管理员无法删除渠道。

Q: 禁用渠道后会怎样？
A: 禁用后该渠道的渠道码将无法被扫描，用户扫描后会提示渠道已禁用。

Q: 删除渠道后渠道码还能用吗？
A: 删除渠道后，该渠道下所有渠道码将失效，无法正常使用。

### 场景：为活动启用渠道码

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可为活动启用任意渠道的渠道码 |
| 群组管理员 | ✓ | 可为活动启用渠道码 |
| 租户管理员 | ✓ | 可为活动启用渠道码 |
| 全局管理员 | ✓ | 可为活动启用渠道码 |

#### 操作入口

活动详情页 → 活动设置 → 渠道码

#### 操作流程

1. 进入活动的渠道码页面
2. 如果页面为空，点击「新增渠道」创建新渠道并自动启用
3. 如果已有渠道，点击渠道卡片即可启用该渠道的渠道码
4. 启用成功后自动跳转至渠道码详情页

#### 限制与约束

- 每场活动最多可启用 100 个渠道码
- 已启用的渠道码不可重复启用
- 禁用状态的渠道无法启用渠道码

#### 常见问题

Q: 为什么提示"该渠道已禁用"？
A: 该渠道已被禁用，需要先在渠道管理中启用该渠道，再启用渠道码。

Q: 启用渠道码后可以删除吗？
A: 可以禁用渠道来使渠道码失效，但渠道本身不可删除（仅群组主理人可删除）。

### 场景：查看渠道码详情和数据

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可查看所有渠道码详情和用户数据 |
| 群组管理员 | ✓ | 可查看自己创建的渠道码详情 |
| 租户管理员 | ✓ | 可查看所有渠道码详情 |
| 全局管理员 | ✓ | 可查看所有渠道码详情 |

#### 操作入口

活动详情页 → 活动设置 → 渠道码 → 选择渠道码

#### 操作流程

**查看渠道码信息**

1. 进入渠道码详情页，可查看渠道名称、创建人、创建时间
2. 页面显示总浏览人数和浏览次数
3. 右侧展示渠道码二维码

**下载渠道码**

1. 点击二维码下方的「下载」按钮
2. 在弹出的卡片中可预览和保存二维码图片

**查看渠道用户**

1. 页面下方展示通过该渠道码访问的用户列表
2. 可通过筛选条件查看不同状态的用户：
   - 已参与：已报名或签到的用户
   - 未参与：访问但未报名的用户
   - 游客：未登录或未识别的用户

**修改渠道信息**

- 仅群组主理人可修改渠道名称
- 点击渠道名称旁的编辑图标进行修改

#### 限制与约束

- 渠道用户列表支持分页加载，每次加载 20 条
- 游客用户无法查看详细信息

#### 常见问题

Q: 为什么二维码不显示？
A: 二维码生成需要时间，请稍等片刻刷新页面。

Q: 如何区分不同来源的用户？
A: 通过渠道码详情页的用户列表，可查看该渠道下所有访问用户及其参与状态。

Q: 为什么有些用户显示为"游客"？
A: 游客指未登录或未识别的用户，系统无法获取其详细信息。

### 场景：渠道码与分享追踪

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 所有角色 | ✓ | 所有用户扫描渠道码后都会被记录来源 |

#### 操作入口

分享渠道码二维码 → 用户扫描 → 系统自动记录

#### 操作流程

1. 将渠道码二维码分享到对应的推广渠道（微信群、小红书等）
2. 用户扫描二维码进入活动页面
3. 系统自动记录该用户的来源渠道
4. 运营者可在渠道码详情页查看该渠道的扫码数据

#### 限制与约束

- 渠道码仅记录首次扫描来源
- 同一用户多次扫描同一渠道码，仅记录一次

#### 常见问题

Q: 渠道码和普通分享链接有什么区别？
A: 渠道码可以追踪用户来源渠道，而普通分享链接无法区分来源。

Q: 用户扫描后没有记录怎么办？
A: 请确认用户是否已登录，未登录用户会显示为"游客"。

# 支付与收费

## 概述

支付与收费模块为喜多活动提供完整的费用管理能力。当社团管理员在创建活动时开启收费功能，参与者在报名活动时需要通过微信支付缴纳相应费用。系统支持会员免费参与、管理员单笔免单、取消报名自动退款等灵活的收费策略，确保活动费用管理既规范又人性化。

本模块面向三类角色：普通用户在报名付费活动中通过微信支付完成缴费；社团主理人（CO）和社团管理员（CA）可以为成员设置会员身份（VIP）使其免费参与付费活动，也可以为特定订单设置免费；社区管理员（TA）负责为群组配置收费功能及最高收费金额上限。

## 核心概念

- **收费活动**：社团管理员在创建活动时开启了收费功能，参与者报名时需要缴纳费用的活动。
- **会员（VIP）**：由社团主理人或管理员为群组成员设置的付费身份，拥有 VIP 身份的成员可以免费参与开启了"会员免费"功能的付费活动。
- **订单**：用户报名收费活动后自动生成的支付记录，包含费用金额、支付状态等信息。
- **支付状态**：订单当前的支付情况，包括未支付、已支付、会员免费、管理员免单等状态。
- **最高收费金额**：社区管理员为群组设定的活动收费上限，所有活动的报名费用不得超过此金额。

## 操作指南

### 场景：活动报名付费（微信支付）

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✓ | 报名收费活动时自动触发支付流程 |
| 社团主理人（CO） | ✓ | 同普通用户权限 |
| 社团管理员（CA） | ✓ | 同普通用户权限 |

#### 操作入口

社区首页 → 选择群组 → 进入活动详情页

#### 操作流程

1. 进入收费活动的详情页面，页面会显示活动的报名费用金额。
2. 点击底部「点击报名」按钮，系统自动生成支付订单并弹出支付确认弹窗。
3. 弹窗中展示活动名称、报名费用金额和支付说明，确认无误后点击「确认支付」。
4. 系统调用微信支付，跳转至微信支付界面完成付款。
5. 支付成功后系统提示「支付成功」，报名状态更新为已支付。
6. 若点击「稍后支付」，弹窗关闭，报名状态保持「未支付」，可随时在活动详情页点击「继续支付」完成付款。

#### 限制与约束

- 仅当活动开启了收费功能且报名费用大于零时，才会触发支付流程。
- 已报名但未支付的用户，活动详情页按钮会显示为「继续支付」。
- 支付过程中点击取消，系统提示「取消支付」，订单状态不变。
- 若用户是该群组的 VIP 会员，且活动开启了「会员免费」功能，报名时将自动跳过支付，订单状态为会员免费。

#### 常见问题

Q: 报名时没有弹出支付窗口怎么办？
A: 该活动可能未开启收费功能，或用户已拥有该活动的 VIP 免费资格。

Q: 支付失败了怎么办？
A: 系统会提示「支付失败」，可以在活动详情页重新点击「继续支付」再次尝试。

Q: 取消报名后钱会退回来吗？
A: 已支付的订单在取消报名时会自动发起退款，退款将原路退回至微信支付账户。

### 场景：支付订单查询

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✗ | 不可查询订单支付状态 |
| 社团主理人（CO） | ✓ | 可查询订单支付状态 |
| 社团管理员（CA） | ✓ | 可查询订单支付状态 |

#### 操作入口

社区首页 → 选择群组 → 进入活动详情页 → 活动管理 → 订单管理

#### 操作流程

1. 在活动管理界面查看报名用户的订单列表。
2. 选择需要查询的订单，查看其当前支付状态。
3. 系统展示该订单的详细支付信息，包括支付状态、支付时间等。

#### 限制与约束

- 仅社团主理人（CO）和社团管理员（CA）可查看订单支付状态。
- 订单支付状态由微信支付系统自动更新，管理员不可手动修改。

#### 常见问题

Q: 订单显示「支付中」是什么意思？
A: 表示用户已发起微信支付但系统尚未收到支付结果通知，通常会在短时间内自动更新。

Q: 订单显示「已关闭」是什么意思？
A: 表示用户在微信支付环节超时未完成支付，订单自动关闭，用户可重新报名支付。

### 场景：设置会员（VIP）

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✗ | 不可设置 VIP |
| 社团主理人（CO） | ✓ | 可为群组内任意成员设置 VIP |
| 社团管理员（CA） | ✓ | 可为群组内任意成员设置 VIP |

#### 操作入口

社区首页 → 选择群组 → 成员管理 → 选择成员 → 设置 VIP

#### 操作流程

1. 进入群组的成员管理页面，找到需要设置 VIP 的成员。
2. 点击该成员，进入成员详情或操作菜单。
3. 选择「设置 VIP」选项。
4. 设置 VIP 到期日期（可选，留空则无期限限制）。
5. 确认提交，系统完成 VIP 设置。

#### 限制与约束

- 该群组必须已开启收费功能，否则无法设置 VIP。
- 设置 VIP 后，该成员所有进行中的付费活动订单会自动变更为「会员免费」状态。
- 取消 VIP 后，该成员进行中的「会员免费」订单会恢复为「未支付」状态，需重新支付。

#### 常见问题

Q: 为什么无法为成员设置 VIP？
A: 请确认该群组已开启收费功能，未开启收费功能的群组不支持 VIP 设置。

Q: 设置 VIP 后，之前已经支付的订单会退款吗？
A: 不会。VIP 设置仅影响进行中的未支付订单，已支付的订单不受影响。

Q: VIP 到期后会自动取消吗？
A: 系统会根据到期日期判断 VIP 身份是否有效，到期后自动失去 VIP 权益。

### 场景：设置单笔订单免费

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✗ | 不可设置订单免费 |
| 社团主理人（CO） | ✓ | 可为任意用户的订单设置免费 |
| 社团管理员（CA） | ✓ | 可为任意用户的订单设置免费 |

#### 操作入口

社区首页 → 选择群组 → 进入活动详情页 → 活动管理 → 订单管理 → 选择订单 → 设置免费

#### 操作流程

1. 在活动管理的订单列表中，找到需要设置免费的用户订单。
2. 点击该订单，选择「设置免费」操作。
3. 可填写免费备注说明（可选）。
4. 确认提交，系统将该订单状态变更为「管理员免单」。

#### 限制与约束

- 已完成支付的订单无法设置为免费。
- 已设置为免费的订单，管理员可以取消免费并恢复原价。
- 取消免单后，订单状态恢复为「未支付」，用户需要重新支付。

#### 常见问题

Q: 为什么无法为订单设置免费？
A: 如果订单已完成支付，系统不允许设置为免费，以避免财务混乱。

Q: 设置免费后可以取消吗？
A: 可以。取消免费后订单会恢复原价，用户需要重新支付才能完成报名。

### 场景：VIP 免费参与活动

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✓（需 VIP 身份） | 拥有 VIP 身份的用户自动享受免费权益 |
| 社团主理人（CO） | ✓ | 同普通用户权限 |
| 社团管理员（CA） | ✓ | 同普通用户权限 |

#### 操作入口

社区首页 → 选择群组 → 进入活动详情页

#### 操作流程

1. 拥有 VIP 身份的用户进入收费活动详情页。
2. 点击「点击报名」按钮。
3. 系统检测到用户 VIP 身份且活动支持会员免费，自动跳过支付环节。
4. 报名成功，订单状态直接显示为「会员免费」。

#### 限制与约束

- 用户必须是该群组的有效 VIP 会员。
- 活动必须开启了「会员免费」功能（由社团管理员在活动创建时设置）。
- 仅对进行中的活动有效，历史活动不适用。
- VIP 身份到期后，后续活动报名需正常支付。

#### 常见问题

Q: 我是 VIP 但报名时还是要求付费？
A: 请确认该活动已开启「会员免费」功能，此功能需要活动创建者单独开启。

Q: VIP 到期后正在进行的活动怎么办？
A: 已完成报名的活动不受影响，VIP 到期后仅影响后续新活动的报名。

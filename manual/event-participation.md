# 活动参与

## 概述

活动参与是喜多小程序的核心功能之一，支持用户浏览活动、报名参加、签到打卡和签退等完整参与流程。活动由群组管理员或群组主理人创建，普通用户可以通过活动详情页了解活动信息并参与其中。

本功能解决了社群活动组织者难以管理参与者、用户无法便捷参与活动的问题，通过线上报名和打卡机制，实现了活动全流程的数字化管理。

## 核心概念

- 活动（Event）：由群组管理员创建的定时活动，包含基本信息、打卡设置和报名设置
- 打卡活动（CIE）：具有报名打卡功能的活动，支持报名、打卡、签退等操作
- 普通活动（CE）：仅展示信息的活动，不支持报名打卡
- 报名（Sign Up）：用户注册参加活动的行为，活动创建者可设置报名时间窗口和名额限制
- 打卡（Check In）：用户在活动期间标记到场的行为，支持位置验证
- 签退（Check Out）：用户在活动结束后标记离开的行为，需管理员手动开启
- 打卡身份（Persona）：用户参与活动时的虚拟身份，包含昵称和头像
- 分享场景（Share Scene）：记录用户通过何种方式进入活动，如扫码、分享链接等

## 操作指南

### 场景：查看活动详情

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 全局管理员 | ✓ | 可查看所有活动 |
| 租户管理员 | ✓ | 可查看租户下所有活动 |
| 群组主理人 | ✓ | 可查看群组内所有活动 |
| 群组管理员 | ✓ | 可查看群组内所有活动 |
| 普通用户 | ✓ | 可查看已发布的活动 |

#### 操作入口

社区首页 → 选择群组 → 点击活动卡片 → 进入活动详情页

#### 操作流程

1. 在社区首页或群组首页，浏览活动列表
2. 点击感兴趣的活动卡片，进入活动详情页
3. 查看活动标题、时间、地点、描述等基本信息
4. 查看活动图片和附件（如有）
5. 查看评论区（如已启用）
6. 查看报名状态和打卡按钮

#### 限制与约束

- 未发布的活动（草稿状态）不会在列表中展示
- 需要审核的活动，审核通过前仅创建者和管理员可查看
- 活动详情页会记录访问来源，用于渠道效果分析

#### 常见问题

Q: 为什么看不到某个活动？
A: 可能原因：1) 活动尚未发布；2) 活动设置了隐私权限；3) 你不在该活动所属群组中。

Q: 活动图片加载不出来？
A: 请检查网络连接，或稍后重试。如持续无法加载，请联系群组管理员。

### 场景：报名参加活动

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 全局管理员 | ✓ | 可报名任何活动 |
| 租户管理员 | ✓ | 可报名任何活动 |
| 群组主理人 | ✓ | 可报名群组内活动 |
| 群组管理员 | ✓ | 可报名群组内活动 |
| 普通用户 | ✓ | 可报名已发布且开放报名的活动 |

#### 操作入口

活动详情页 → 点击底部「报名」按钮

#### 操作流程

1. 进入活动详情页，查看活动信息
2. 确认活动已开启报名功能（底部显示报名按钮）
3. 点击「报名」按钮
4. 首次参与需创建打卡身份（设置昵称和头像）
5. 如活动需要填写问卷，需先完成问卷提交
6. 如活动设置了服务号通知，需先关注服务号
7. 确认报名信息，完成报名
8. 如活动需要付费，跳转支付流程完成支付

#### 限制与约束

- 报名时间窗口：仅在报名开始时间至结束时间内可报名
- 名额限制：活动设置了报名上限时，名额满后无法报名
- 付费活动：需完成支付才算报名成功
- 问卷要求：如活动启用了问卷，需先提交问卷才能报名
- 服务号要求：如活动启用了服务号通知，需先关注服务号

#### 常见问题

Q: 为什么报名按钮置灰？
A: 可能原因：1) 当前不在报名时间窗口内；2) 报名名额已满；3) 活动未开启报名功能。

Q: 报名后可以取消吗？
A: 可以。在活动详情页点击「我的」查看报名信息，选择取消报名。已支付的活动取消后将自动退款。

Q: 报名需要付费吗？
A: 由活动创建者决定。如活动设置了报名费用，需完成支付才算报名成功。群组会员可享受免费报名（如活动创建者设置了会员免费）。

### 场景：打卡签到

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 全局管理员 | ✓ | 可打卡任何活动 |
| 租户管理员 | ✓ | 可打卡任何活动 |
| 群组主理人 | ✓ | 可打卡群组内活动 |
| 群组管理员 | ✓ | 可打卡群组内活动 |
| 普通用户 | ✓ | 可打卡已报名的活动 |

#### 操作入口

活动详情页 → 点击底部「打卡」按钮

#### 操作流程

1. 进入活动详情页，确认已报名或活动允许直接打卡
2. 点击「打卡」按钮
3. 如活动要求定位打卡，需开启定位权限并确认位置
4. 确认打卡信息，完成打卡
5. 打卡成功后，按钮状态更新为「已打卡」

#### 限制与约束

- 打卡时间窗口：仅在打卡开始时间至结束时间内可打卡
- 定位验证：如活动开启了定位要求，需在指定距离内才能打卡
- 问卷要求：如活动启用了问卷，需先提交问卷才能打卡
- 每人限打一次：同一用户在同一活动中只能打卡一次

#### 常见问题

Q: 为什么打卡按钮置灰？
A: 可能原因：1) 当前不在打卡时间窗口内；2) 你已打过卡；3) 需要先报名才能打卡。

Q: 打卡提示距离过远？
A: 活动创建者可能设置了打卡距离限制，请确保在活动地点附近打卡。

Q: 打卡失败怎么办？
A: 请检查：1) 网络连接是否正常；2) 定位权限是否开启；3) 是否在打卡时间窗口内。如问题持续，请联系群组管理员。

### 场景：签退

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 全局管理员 | ✓ | 可签退任何活动 |
| 租户管理员 | ✓ | 可签退任何活动 |
| 群组主理人 | ✓ | 可签退群组内活动 |
| 群组管理员 | ✓ | 可签退群组内活动 |
| 普通用户 | ✓ | 可签退已打卡的活动 |

#### 操作入口

活动详情页 → 点击底部「签退」按钮

#### 操作流程

1. 进入活动详情页，确认已打卡且活动开启了签退功能
2. 点击「签退」按钮
3. 确认签退信息，完成签退
4. 签退成功后，按钮状态更新为「已签退」

#### 限制与约束

- 签退需管理员手动开启：活动创建者需在活动设置中手动开启签退功能
- 签退时间窗口：签退功能开启后，在签退结束时间前可签退
- 必须已打卡：只有已打卡的用户才能签退

#### 常见问题

Q: 为什么没有签退按钮？
A: 活动创建者可能未开启签退功能，或签退时间窗口未到。

Q: 签退后可以修改吗？
A: 不可以。签退记录一旦生成，无法修改或撤销。

### 场景：取消报名

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✓ | 仅可取消自己的报名 |

#### 操作入口

活动详情页 → 点击底部「我的」按钮 → 查看报名信息 → 点击「取消报名」

#### 操作流程

1. 进入活动详情页，点击底部「我的」按钮
2. 查看当前报名状态
3. 点击「取消报名」按钮
4. 确认取消操作
5. 如已支付，系统将自动发起退款

#### 限制与约束

- 已打卡的用户无法取消报名
- 退款处理：已支付的活动取消报名后，费用将原路退回
- 退款中状态：退款处理期间，无法再次报名该活动

#### 常见问题

Q: 取消报名后可以重新报名吗？
A: 可以，但需在报名时间窗口内且有名额。

Q: 退款多久到账？
A: 退款到账时间取决于支付渠道，通常1-3个工作日。

### 场景：管理员管理参与人

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可管理群组内所有活动的参与人 |
| 群组管理员 | ✓ | 仅可管理自己创建的活动的参与人 |

#### 操作入口

活动详情页 → 点击底部「设置」按钮 → 进入参与人管理页面

#### 操作流程

1. 进入活动详情页，点击底部「设置」按钮
2. 选择「参与人管理」
3. 可查看当前所有参与人列表
4. 可添加或移除参与人
5. 可修改参与人的备注信息

#### 限制与约束

- 仅管理员可操作
- 已打卡或已签退的参与人无法移除
- 可添加虚拟成员作为参与人

#### 常见问题

Q: 为什么无法移除某个参与人？
A: 该参与人可能已打卡或签退，系统不允许移除已参与的用户。

Q: 如何添加虚拟成员？
A: 在参与人管理页面选择「添加成员」，可创建虚拟成员并添加到活动中。

### 场景：管理员扫码签到

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可为群组内活动扫码签到 |
| 群组管理员 | ✓ | 仅可为自己创建的活动扫码签到 |

#### 操作入口

活动详情页 → 点击底部「设置」按钮 → 选择「扫码签到」

#### 操作流程

1. 进入活动详情页，点击底部「设置」按钮
2. 选择「扫码签到」
3. 生成现场签到二维码（有效期5秒）
4. 参与者扫描二维码完成签到
5. 或使用「扫用户码」功能，扫描参与者的个人二维码完成签到

#### 限制与约束

- 仅管理员可操作
- 现场二维码有效期5秒，过期需重新生成
- 用户码有效期40秒，过期需重新生成

#### 常见问题

Q: 二维码过期了怎么办？
A: 重新点击生成即可，新二维码会覆盖旧二维码。

Q: 扫码签到和普通打卡有什么区别？
A: 扫码签到由管理员发起，无需参与者操作；普通打卡由参与者自行操作。

# 裂变分析

## 概述

裂变分析是喜多为活动运营者提供的分享数据追踪和分析功能，用于深入了解活动分享效果和裂变传播链路。通过该功能，运营者可以查看每个分享人的分享数据、触达人数、转化情况，以及完整的裂变传播路径。

该功能主要面向活动管理员和群组管理员，帮助他们评估活动推广效果，识别高价值分享者，优化活动运营策略。

## 核心概念

- **分享码**：每个用户分享活动时系统自动生成的唯一标识，用于追踪分享效果
- **直接分享**：用户通过分享码直接触达的人数（包括二维码扫码和链接点击）
- **裂变分享**：通过分享链路间接触达的人数，体现多级传播效果
- **分享场景**：用户触达活动的渠道，包括二维码扫码、链接点击、平台浏览等
- **分享链路**：用户从首次触达到参与活动的完整路径，记录了传播链条
- **受邀记录**：通过某分享人的分享码触达的用户列表

## 操作指南

### 场景：查看分享裂变统计列表

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 拥有查看所有分享数据的权限 |
| 群组管理员 | ✓ | 拥有查看分享数据的权限 |
| 群组成员 | ✗ | 无法查看分享统计 |

#### 操作入口

活动管理页面 → 数据分析 → 分享裂变统计

#### 操作流程

1. 进入活动管理页面，点击"数据分析"入口
2. 在数据分析页面，找到并点击"分享裂变统计"选项
3. 系统加载并显示分享人列表，包含以下信息：
   - 分享人头像和昵称
   - 首次分享时间
   - 分享来源（活动创建人、平台浏览、通过某人分享）
   - 分享统计数据（扫码数、链接数、参与人数、裂变触达数）
4. 支持下拉刷新和上拉加载更多
5. 点击任意分享人可查看详细信息

#### 限制与约束

- 只有群组管理员或群组主理人才能查看分享统计
- 数据按首次分享时间倒序排列
- 支持分页加载，每页10条记录

#### 常见问题

Q: 为什么我无法查看分享统计？
A: 分享统计功能仅对群组管理员和群组主理人开放，请确认您是否具有相应权限。

Q: 分享统计数据会实时更新吗？
A: 分享统计数据会实时更新，但可能存在几分钟的延迟。

Q: 如何导出分享统计数据？
A: 目前暂不支持导出功能，建议通过截图或手动记录关键数据。

### 场景：查看分享人详情

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 拥有查看分享人详情的权限 |
| 群组管理员 | ✓ | 拥有查看分享人详情的权限 |
| 群组成员 | ✗ | 无法查看分享人详情 |

#### 操作入口

分享裂变统计列表 → 点击分享人卡片

#### 操作流程

1. 在分享裂变统计列表中，点击要查看详情的分享人
2. 系统跳转到分享人详情页面，显示以下信息：
   - **分享人信息**：头像、昵称、分享活动名称
   - **分享链路**：该用户是如何触达活动的（活动创建人、平台浏览、通过某人分享）
   - **关键时间**：首次分享时间、报名时间、签到时间、签退时间
   - **直接分享统计**：通过该用户分享码直接触达的人数、报名数、参与数、支付金额
   - **裂变分享统计**：通过该用户分享链路间接触达的人数、报名数、参与数、支付金额
3. 在"TA邀请的"区域，可以查看该分享人邀请的所有用户列表
4. 支持筛选：参与、未参与、游客三种状态

#### 限制与约束

- 分享链路最多显示4级，超过4级会省略中间层级
- 受邀记录支持分页加载，每页12条记录
- 可以点击邀请链路中的用户跳转查看其详情

#### 常见问题

Q: 什么是"直接分享"和"裂变分享"？
A: 直接分享是指通过该用户分享码直接触达的人数；裂变分享是指通过该用户分享链路间接触达的人数，体现多级传播效果。

Q: 为什么有些用户显示"活动创建人"？
A: 表示该用户是活动的创建者，其分享链路从活动创建开始。

Q: 为什么有些用户显示"通过平台浏览进入"？
A: 表示该用户是通过小程序平台的浏览功能发现活动的，不是通过其他用户分享触达的。

Q: 如何查看用户的报名和签到状态？
A: 在邀请列表中，可以筛选"参与"状态的用户，这些用户已完成报名和签到。

### 场景：筛选受邀记录

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 拥有筛选受邀记录的权限 |
| 群组管理员 | ✓ | 拥有筛选受邀记录的权限 |
| 群组成员 | ✗ | 无法筛选受邀记录 |

#### 操作入口

分享人详情页 → "TA邀请的"区域 → 筛选选项

#### 操作流程

1. 在分享人详情页的"TA邀请的"区域
2. 找到筛选选项，包含三个复选框：
   - **参与**：已报名并签到的用户
   - **未参与**：已报名但未签到的用户
   - **游客**：仅访问未报名的用户
3. 点击复选框可切换选中/取消状态
4. 选中状态会实时刷新下方的邀请列表
5. 可以同时选择多个筛选条件

#### 限制与约束

- 筛选条件可以多选组合使用
- 未选中任何筛选条件时，显示所有受邀记录
- 筛选结果数量会实时显示在选项旁

#### 常见问题

Q: 为什么"参与"和"未参与"的数字加起来不等于总数？
A: 因为"游客"是指仅访问未报名的用户，不包含在"参与"和"未参与"中。

Q: 筛选后如何重置？
A: 再次点击已选中的筛选条件即可取消，或取消所有筛选条件即可显示全部记录。

Q: 为什么有些用户同时出现在"参与"和"未参与"中？
A: 这种情况不会发生，每个用户只会有一个状态标签。

### 场景：分析分享效果

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 拥有分析分享效果的权限 |
| 群组管理员 | ✓ | 拥有分析分享效果的权限 |
| 群组成员 | ✗ | 无法分析分享效果 |

#### 操作入口

分享裂变统计列表 → 分享人详情页

#### 操作流程

1. 在分享人详情页，查看以下关键指标：
   - **直接分享统计**：
     - 总计：通过该分享码触达的总人数
     - 链接：通过链接点击触达的人数
     - 扫码：通过二维码扫码触达的人数
     - 报名：通过该分享码报名的人数
     - 参与：通过该分享码参与活动的人数
     - 支付：通过该分享码产生的支付金额
   - **裂变分享统计**：
     - 总计：通过分享链路间接触达的总人数
     - 链接：通过分享链路间接触达的链接点击数
     - 扫码：通过分享链路间接触达的二维码扫码数
     - 报名：通过分享链路间接报名的人数
     - 参与：通过分享链路间接参与的人数
     - 支付：通过分享链路间接产生的支付金额
2. 对比直接分享和裂变分享数据，评估分享效果
3. 识别高价值分享者（裂变数据突出的用户）
4. 分析分享场景（二维码 vs 链接）的效果差异

#### 限制与约束

- 统计数据实时更新
- 金额数据保留两位小数
- 支持查看历史分享数据

#### 常见问题

Q: 如何判断分享效果好坏？
A: 可以从以下几个维度评估：直接分享人数、裂变分享人数、报名转化率、支付金额。裂变数据越高说明传播效果越好。

Q: 为什么有些用户裂变数据很高？
A: 可能是因为该用户影响力大，分享后触达了很多人，或者其分享链路较长，产生了多级传播。

Q: 如何提高分享效果？
A: 可以通过以下方式：选择有影响力的用户作为分享者、优化分享素材、提供分享激励、缩短分享链路。

Q: 支付金额包含退款吗？
A: 支付金额为实际支付金额，不包含退款。如需查看退款情况，需要结合订单数据进一步分析。

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 拥有追踪分享链路的权限 |
| 群组管理员 | ✓ | 拥有追踪分享链路的权限 |
| 群组成员 | ✗ | 无法追踪分享链路 |

#### 操作入口

分享人详情页 → 分享链路

#### 操作流程

1. 在分享人详情页，查看"分享链路"字段
2. 分享链路显示该用户是如何触达活动的：
   - **活动创建人**：该用户是活动创建者
   - **通过平台浏览进入**：该用户通过小程序平台浏览发现活动
   - **通过[用户昵称]分享**：该用户通过其他用户分享触达
3. 如果分享链路有多级，会显示面包屑格式（如：A → B → C）
4. 可以点击链路中的用户昵称，跳转查看该用户的分享详情
5. 通过分享链路可以了解完整的传播路径

#### 限制与约束

- 分享链路最多显示4级
- 超过4级会显示"..."并省略中间层级
- 可以点击链路中的用户跳转查看详情

#### 常见问题

Q: 为什么分享链路显示"活动创建人"？
A: 表示该用户是活动的创建者，其分享链路从活动创建开始，没有上级分享人。

Q: 为什么分享链路显示"通过平台浏览进入"？
A: 表示该用户是通过小程序平台的浏览功能发现活动的，不是通过其他用户分享触达的。

Q: 如何查看完整的传播路径？
A: 可以通过点击链路中的用户昵称，逐级跳转查看完整的传播路径。

Q: 分享链路有什么实际意义？
A: 分享链路可以帮助运营者了解活动的传播路径，识别关键传播节点，优化分享策略。

### 场景：识别高价值分享者

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 拥有识别高价值分享者的权限 |
| 群组管理员 | ✓ | 拥有识别高价值分享者的权限 |
| 群组成员 | ✗ | 无法识别高价值分享者 |

#### 操作入口

分享裂变统计列表

#### 操作流程

1. 在分享裂变统计列表中，关注以下关键指标：
   - **直接分享人数**：通过该用户分享码直接触达的人数
   - **裂变分享人数**：通过该用户分享链路间接触达的人数
   - **报名转化率**：报名人数 / 分享触达人数
   - **支付金额**：通过该用户分享产生的支付金额
2. 重点关注裂变数据高的用户，这些用户具有较强的传播能力
3. 点击进入详情页，深入分析其分享效果
4. 记录高价值分享者，用于后续活动推广合作

#### 限制与约束

- 统计数据实时更新
- 需要结合多个指标综合评估
- 建议定期查看以跟踪分享效果变化

#### 常见问题

Q: 如何定义"高价值分享者"？
A: 高价值分享者通常具备以下特征：裂变数据高、报名转化率高、支付金额大。需要结合多个指标综合评估。

Q: 为什么有些用户直接分享数据不高，但裂变数据很高？
A: 可能是因为该用户触达的人中，有影响力较大的用户进行了二次分享，产生了多级传播效果。

Q: 如何利用高价值分享者？
A: 可以通过以下方式：邀请其参与后续活动、提供专属激励、建立长期合作关系、分析其分享策略并推广。

Q: 分享数据会受活动类型影响吗？
A: 会的，不同类型的活动（如付费活动、免费活动）分享效果会有差异，建议同类活动对比分析。

### 场景：对比分析不同分享场景

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 拥有对比分析的权限 |
| 群组管理员 | ✓ | 拥有对比分析的权限 |
| 群组成员 | ✗ | 无法对比分析 |

#### 操作入口

分享人详情页 → 直接分享统计 / 裂变分享统计

#### 操作流程

1. 在分享人详情页，查看直接分享统计中的"链接"和"扫码"数据
2. 对比以下指标：
   - **链接分享**：通过链接点击触达的人数
   - **扫码分享**：通过二维码扫码触达的人数
3. 分析不同分享场景的效果差异：
   - 链接分享适合线上推广（如社交媒体、群聊）
   - 扫码分享适合线下场景（如活动现场、海报）
4. 根据分析结果优化分享策略

#### 限制与约束

- 统计数据实时更新
- 需要结合活动场景综合分析
- 建议在不同推广渠道分别设置分享码

#### 常见问题

Q: 链接分享和扫码分享有什么区别？
A: 链接分享适合线上场景，用户点击链接即可访问活动页面；扫码分享适合线下场景，用户扫描二维码即可访问活动页面。

Q: 如何提高扫码分享效果？
A: 可以通过以下方式：将二维码放置在显眼位置、提供扫码激励、优化二维码样式、确保二维码清晰可扫描。

Q: 如何提高链接分享效果？
A: 可以通过以下方式：优化分享文案、选择合适的分享渠道、提供分享激励、制作吸引人的分享图片。

Q: 为什么有些用户同时有链接和扫码数据？
A: 可能是因为该用户在不同场景下使用了不同的分享方式，或者其分享被其他人以不同方式转发。

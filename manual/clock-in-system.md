# 打卡系统

## 概述

打卡系统是喜多平台为社团提供的活动签到管理工具。社团管理员可以创建打卡活动，设置签到时间、签到地点、地理围栏、报名时段和名额限制等参数；普通用户可以通过地理位置打卡、现场亮码、扫码用户码、碰一碰等多种方式完成签到和签退。系统支持免费活动和收费活动，提供报名管理、打卡记录导出、照片管理等完整的活动运营能力。

本模块面向三类角色：社团管理员（CA）负责创建和管理打卡活动；社团主理人（CO）拥有社团内全部管理权限；普通用户参与打卡活动、完成报名和签到。

## 核心概念

- **打卡活动**：由社团管理员创建的签到类活动，包含签到时间、签到地点、地理围栏等配置
- **签到时间**：打卡活动的有效签到时间段，用户必须在此时间段内完成签到
- **签退时间**：可选的签退时间段，开启后用户需要在签退时间段内完成签退
- **地理围栏**：签到地点设置的可打卡距离范围，用户需在此范围内才能打卡
- **报名**：活动开始前的预约环节，可设置报名时间段和名额上限
- **打卡身份**：用户参与打卡活动时使用的身份信息，包含昵称、学号、手机号等
- **现场亮码**：管理员在活动现场展示二维码，用户扫码完成签到
- **用户码**：用户个人的专属二维码，管理员扫码即可为用户签到
- **碰一碰签**：通过 NFC 设备触碰完成签到的方式

## 操作指南

### 场景：创建打卡活动

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团主理人（CO） | ✓ | 拥有社团内全部管理权限 |
| 社团管理员（CA） | ✓ | 可在所管理的社团内创建打卡活动 |
| 普通用户 | ✗ | 无创建权限 |

#### 操作入口

群组首页 → 创建活动 → 选择「打卡」类型

#### 操作流程

1. 进入目标群组，点击创建活动按钮
2. 选择活动类型为「打卡」
3. 填写活动名称和活动描述
4. 设置活动时间范围（起止时间）
5. 配置签到时间（签到开始时间和结束时间）
6. 如需签退功能，开启「签退」并设置签退时间段
7. 如需报名功能，开启「报名」并设置报名开始/截止时间和名额上限
8. 如需地理位置打卡，开启「定位签到」并设置打卡地点和可打卡距离（米）
9. 如需收费，开启收费功能并设置价格，可选择「会员免费」
10. 如需 NFC 签到，开启「碰一碰签」
11. 上传活动海报和照片
12. 点击「发布」完成创建

#### 限制与约束

- 活动名称、时间、签到时间段为必填项
- 报名名额上限为可选设置
- 签到时间必须在活动时间范围内
- 签退时间必须在签到时间之后
- 照片最多可上传 36 张

#### 常见问题

Q: 为什么活动创建后提示「审核中」？
A: 当群组开启了活动审核功能时，新建的活动需要管理员审核通过后才会发布，审核结果会通过服务号消息通知。

Q: 可以创建不限地点的打卡活动吗？
A: 可以。不开启「定位签到」时，用户无需在特定地点即可打卡签到。

### 场景：编辑打卡活动设置

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团主理人（CO） | ✓ | 可编辑群组内所有活动 |
| 社团管理员（CA） | 仅自己创建的 | 只能编辑自己创建的活动 |
| 租户管理员（TA） | ✓ | 可编辑租户下所有活动 |
| 普通用户 | ✗ | 无编辑权限 |

#### 操作入口

打卡详情页 → 底部「设置」按钮 → 控制面板 → 编辑活动

#### 操作流程

1. 进入打卡详情页，点击底部「设置」图标
2. 在控制面板中点击「编辑活动」
3. 修改需要调整的活动参数
4. 点击「保存」提交修改

#### 限制与约束

- 活动修改可能需要管理员审核（取决于群组设置）
- 已有用户报名或打卡的活动，部分参数可能受限

#### 常见问题

Q: 编辑活动后为什么提示「审核中」？
A: 群组开启了活动审核时，活动修改也需要审核通过后才能生效。

Q: 为什么「编辑活动」按钮置灰？
A: 当前用户不是活动创建者、群组主理人或租户管理员时，无法编辑该活动。

### 场景：用户报名

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团主理人（CO） | ✓ | 可报名参与活动 |
| 社团管理员（CA） | ✓ | 可报名参与活动 |
| 普通用户 | ✓ | 需已登录且在报名时间段内 |

#### 操作入口

打卡详情页 → 底部「点击报名」按钮

#### 操作流程

1. 进入打卡详情页，查看活动信息
2. 确认活动已开启报名功能，且当前在报名时间段内
3. 点击底部「点击报名」按钮
4. 如活动需要付费，跳转支付页面完成支付
5. 报名成功后显示报名成功提示

#### 限制与约束

- 必须在报名时间段内操作
- 名额有限时，名额报满后无法继续报名
- 需要先创建打卡身份才能报名
- 收费活动需完成支付才算报名成功
- 会员免费活动需用户为群组会员

#### 常见问题

Q: 报名按钮显示「名额已满」怎么办？
A: 表示活动报名名额已满，无法继续报名。可联系管理员增加名额或等待有人取消报名释放名额。

Q: 报名后可以取消吗？
A: 可以。在打卡详情页点击「我的」，在参与详情中点击「取消报名」。已付费的活动取消报名后费用将原路退回。

Q: 报名按钮显示「继续支付」是什么意思？
A: 表示之前已报名但未完成支付，点击后可继续完成支付流程。

### 场景：取消报名

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 所有已报名用户 | ✓ | 仅限取消自己的报名 |

#### 操作入口

打卡详情页 → 底部「我的」按钮 → 参与详情 → 取消报名

#### 操作流程

1. 进入打卡详情页，确认已报名
2. 点击底部「我的」图标查看参与详情
3. 在参与详情弹窗中点击「取消报名」
4. 确认取消操作
5. 已付费活动将提示费用将原路退回

#### 限制与约束

- 报名已结束的活动无法取消报名
- 退款中的报名无法重复取消

#### 常见问题

Q: 取消报名后费用多久退回？
A: 已支付的费用将原路退回至原支付账户，具体到账时间取决于支付平台。

### 场景：用户签到（普通打卡）

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 所有已报名/已登录用户 | ✓ | 需在签到时间段内 |

#### 操作入口

打卡详情页 → 底部「点击打卡」按钮

#### 操作流程

1. 进入打卡详情页，确认当前在签到时间段内
2. 如开启了地理位置打卡，确保已授权位置权限并在打卡范围内
3. 点击底部「点击打卡」按钮
4. 系统验证位置信息（如需）后完成签到
5. 签到成功后显示成功提示

#### 限制与约束

- 必须在签到时间段内操作
- 地理位置打卡需在设定的距离范围内
- 需要已创建打卡身份
- 需要授权位置权限（地理位置打卡时）

#### 常见问题

Q: 提示「距离打卡点还有 XX 米，请靠近后打卡」怎么办？
A: 表示当前位置不在打卡范围内，需要靠近打卡地点后重试。

Q: 提示「获取位置失败，请检查GPS是否开启」怎么办？
A: 请在手机设置中开启 GPS 定位服务，并确保微信已获得位置权限。

Q: 提示「你拒绝了位置权限，无法打卡」怎么办？
A: 需要在手机设置中为微信开启位置权限。点击弹窗中的「去授权」可跳转设置页面。

### 场景：地理位置打卡（围栏校验）

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 所有已报名用户 | ✓ | 需在签到时间段和打卡范围内 |

#### 操作入口

打卡详情页 → 底部「点击打卡」按钮 → 进入地图打卡页面

#### 操作流程

1. 进入打卡详情页，点击「打卡」按钮
2. 系统自动获取当前位置并在地图上显示打卡地点
3. 查看与打卡点的距离，确认在可打卡范围内
4. 点击「点击打卡」按钮完成签到
5. 可点击「打开导航」跳转地图导航至打卡地点

#### 限制与约束

- 需要授权微信位置权限
- 需要开启手机 GPS 定位
- 必须在设定的地理围栏距离范围内

#### 常见问题

Q: 地图页面显示「定位中...」一直不动？
A: 请检查手机 GPS 是否开启，以及微信位置权限是否已授权。

### 场景：用户签退

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 已签到用户 | ✓ | 需在签退时间段内 |

#### 操作入口

打卡详情页 → 底部「点击签退」按钮

#### 操作流程

1. 进入打卡详情页，确认已签到且当前在签退时间段内
2. 点击底部「点击签退」按钮
3. 系统完成签退操作
4. 签退成功后显示成功提示

#### 限制与约束

- 需要管理员已开启签退功能
- 必须在签退时间段内操作
- 需要先完成签到才能签退

#### 常见问题

Q: 为什么没有签退按钮？
A: 管理员未开启签退功能，或当前不在签退时间段内。

### 场景：现场亮码签到

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团管理员（CA） | ✓ | 可展示二维码供用户扫码 |
| 社团主理人（CO） | ✓ | 可展示二维码供用户扫码 |
| 普通用户 | ✓ | 扫描管理员展示的二维码完成签到 |

#### 操作入口

打卡详情页 → 底部「设置」按钮 → 控制面板 → 亮码签

#### 操作流程（管理员）

1. 进入打卡详情页，点击底部「设置」图标
2. 在控制面板中点击「亮码签」
3. 屏幕展示签到二维码，供用户扫码
4. 二维码会自动刷新，无需手动操作

#### 操作流程（用户）

1. 向管理员出示小程序内的个人用户码
2. 或扫描管理员展示的现场二维码完成签到

#### 限制与约束

- 二维码每隔一定时间自动刷新（默认30秒）
- 仅管理员可展示现场签到码

#### 常见问题

Q: 二维码刷新后之前扫的还有效吗？
A: 二维码刷新前已扫码签到的记录不受影响。

### 场景：管理员扫用户码签到

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团管理员（CA） | ✓ | 可扫用户码完成签到 |
| 社团主理人（CO） | ✓ | 可扫用户码完成签到 |
| 普通用户 | ✗ | 无扫码权限 |

#### 操作入口

打卡详情页 → 底部「设置」按钮 → 控制面板 → 扫用户签

#### 操作流程

1. 进入打卡详情页，点击底部「设置」图标
2. 在控制面板中点击「扫用户签」
3. 扫描用户的个人二维码
4. 系统自动完成该用户的签到
5. 弹窗提示是否继续扫码

#### 限制与约束

- 仅管理员可操作
- 如活动设置了问卷，扫用户签将跳过问卷填写

#### 常见问题

Q: 提示「本活动已设置问卷，扫用户签将跳过填写，是否继续？」是什么意思？
A: 活动配置了问卷，管理员扫码签到会跳过用户的问卷填写环节。如需用户填写问卷，请引导用户自行打卡。

### 场景：NFC 碰一碰签到

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团管理员（CA） | ✓ | 可开启/关闭 NFC 签到 |
| 社团主理人（CO） | ✓ | 可开启/关闭 NFC 签到 |
| 普通用户 | ✓ | 碰一碰设备完成签到 |

#### 操作入口

打卡详情页 → 底部「设置」按钮 → 控制面板 → 碰一碰签

#### 操作流程（管理员开启）

1. 进入打卡详情页，点击底部「设置」图标
2. 在控制面板中点击「碰一碰签」
3. 确认开启 NFC 签到功能

#### 操作流程（用户签到）

1. 将手机靠近 NFC 设备完成签到

#### 限制与约束

- 群组需先在后台开通 NFC 功能
- 仅群组主理人可开关此功能

#### 常见问题

Q: 为什么没有「碰一碰签」选项？
A: 群组尚未开通 NFC 功能，请联系管理员开通。

### 场景：管理员手动启停签退

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团管理员（CA） | ✓ | 可手动开启/关闭签退通道 |
| 社团主理人（CO） | ✓ | 可手动开启/关闭签退通道 |

#### 操作入口

打卡详情页 → 底部「设置」按钮 → 控制面板 → 开始签退 / 结束签退

#### 操作流程

1. 进入打卡详情页，点击底部「设置」图标
2. 在控制面板中点击「开始签退」或「结束签退」
3. 确认操作
4. 开启签退后默认持续30分钟，届时自动关闭

#### 限制与约束

- 开启签退后默认30分钟自动截止
- 可在截止前手动结束签退

#### 常见问题

Q: 签退通道关闭后还能签退吗？
A: 不能。签退通道关闭后用户无法再进行签退操作。

### 场景：打卡记录查看与管理

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团管理员（CA） | ✓ | 可查看所有参与人的打卡记录 |
| 社团主理人（CO） | ✓ | 可查看所有参与人的打卡记录 |
| 租户管理员（TA） | ✓ | 可查看所有参与人的打卡记录 |
| 普通用户 | ✗ | 仅可查看自己的参与详情 |

#### 操作入口

打卡详情页 → 底部「设置」按钮 → 控制面板 → 参与人

#### 操作流程

1. 进入打卡详情页，点击底部「设置」图标
2. 在控制面板中点击「参与人」
3. 进入参与人列表页，支持「报名记录」和「打卡记录」两个标签切换
4. 可使用搜索框按关键词搜索参与人
5. 点击某条记录可查看参与详情
6. 点击某条记录弹出操作菜单，可选择「参与详情」「填写分工/描述」「私聊」

#### 限制与约束

- 仅管理员可查看所有参与人记录
- 支持分页加载，下拉刷新

#### 常见问题

Q: 为什么我看不到其他人的打卡记录？
A: 普通用户只能查看自己的参与详情，需要管理员身份才能查看所有人的记录。

- 导出文件为 .xlsx 格式

#### 常见问题

Q: 导出的 Excel 包含哪些信息？

### 场景：打卡成员审核（填写分工/描述）

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团管理员（CA） | ✓ | 可为参与人填写分工描述 |

#### 操作入口

打卡详情页 → 底部「设置」按钮 → 控制面板 → 参与人 → 选择参与人 → 填写分工/描述

### 场景：补充图片编辑

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团管理员（CA） | ✓ | 可管理活动照片 |
| 社团主理人（CO） | ✓ | 可管理活动照片 |

#### 操作入口

打卡详情页 → 底部「设置」按钮 → 控制面板 → 精选照片

#### 操作流程

1. 进入打卡详情页，点击底部「设置」图标
2. 在控制面板中点击「精选照片」
3. 可上传新照片、删除已有照片、拖拽调整照片顺序
4. 可勾选某张照片设为「海报」（作为活动封面）
5. 点击「提交修改」保存

#### 限制与约束

- 最多可管理 36 张照片
- 仅管理员可操作
- 拖拽排序支持长按拖动

#### 常见问题

Q: 海报照片有什么作用？
A: 海报照片会作为活动在列表中的封面图展示。

### 场景：打卡详情页

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 所有用户 | ✓ | 可查看打卡活动详情 |

#### 操作入口

群组首页 → 选择打卡活动 → 进入打卡详情页

#### 操作流程

1. 进入打卡详情页，查看活动海报和基本信息
2. 查看活动描述、活动时间、报名时间、签到时间、签退时间
3. 如有签到地点，可点击查看地图位置
4. 查看活动发布者信息，可点击咨询私聊
5. 如有附件，可下载活动附件
6. 底部操作栏：已报名用户显示「我的」，管理员显示「设置」，所有用户可分享活动
7. 滑动可切换至评论区查看和发表评论

#### 限制与约束

- 未登录用户可查看活动信息，但无法报名/打卡
- 活动审核中时底部操作栏不可交互

#### 常见问题

Q: 为什么活动详情页底部操作栏置灰？
A: 活动处于审核中状态，需等待审核通过后才可正常操作。

Q: 为什么显示「打卡即将开始」？
A: 当前时间早于签到开始时间，需等待签到时间到达后才能打卡。

Q: 为什么显示「打卡已结束」？
A: 当前时间已过签到结束时间，打卡通道已关闭。

# AI 辅助功能

## 概述

AI 辅助功能为社团管理员和运营人员提供智能活动描述生成服务。系统基于 AI 大模型，可根据活动标题、描述和海报图片，自动生成专业、生动的活动文案，帮助管理员快速完成活动发布准备。

本功能支持两类活动场景：打卡活动（CIE）和历史活动（CE），其中打卡活动支持海报图片识别，可结合图片内容生成更具针对性的描述。此外，平台管理员可自定义 AI 提示词，调整生成风格以满足不同社团的需求。

## 核心概念

- **打卡活动（CIE）**：支持用户报名与签到打卡的活动类型，可上传海报图片辅助 AI 生成描述
- **历史活动（CE）**：由社团手动补充的过往活动记录，仅用于社团历程展示，不可报名或打卡
- **提示词（Prompt）**：指导 AI 生成内容的指令文本，不同提示词会产生不同风格的活动描述
- **提示词类型**：系统按活动场景区分三种提示词类型：CIE 有图、CIE 无图、CE 描述
- **激活提示词**：在同类型提示词中启用指定提示词，仅有一个处于激活状态

## 操作指南

### 场景：AI 生成打卡活动描述（有海报图片）

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团主理人 | ✓ | 拥有群组内全部管理权限 |
| 社团管理员 | ✓ | 可为管理的群组生成活动描述 |
| 社区管理员 | ✓ | 拥有租户级管理权限 |

#### 操作入口

群组首页 → 选择群组 → 创建打卡活动 → 点击「AI 生成描述」按钮

#### 操作流程

1. 进入创建打卡活动页面，填写活动标题和描述（可选）
2. 上传活动海报图片
3. 点击「AI 生成描述」按钮
4. 系统自动分析海报内容，结合标题和描述生成活动文案
5. 生成完成后，文案将自动填充到描述输入框

#### 限制与约束

- 必须上传至少一张海报图片才能使用有图模式
- 生成结果基于当前激活的 CIE 有图提示词
- 标题和描述至少填写一项，否则无法生成

#### 常见问题

Q: 为什么「AI 生成描述」按钮置灰？
A: 请检查是否已上传海报图片，且标题或描述至少填写了一项。

Q: 生成的描述不满意怎么办？
A: 可修改标题或描述后重新生成，或联系平台管理员调整提示词。

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团主理人 | ✓ | 拥有群组内全部管理权限 |
| 社团管理员 | ✓ | 可为管理的群组生成活动描述 |
| 社区管理员 | ✓ | 拥有租户级管理权限 |

#### 操作入口

群组首页 → 选择群组 → 创建打卡活动 → 点击「AI 生成描述」按钮

#### 操作流程

1. 进入创建打卡活动页面，填写活动标题和描述（至少一项）
2. 不上传海报图片
3. 点击「AI 生成描述」按钮
4. 系统根据标题和描述生成活动文案
5. 生成完成后，文案将自动填充到描述输入框

#### 限制与约束

- 标题和描述至少填写一项，否则无法生成
- 生成结果基于当前激活的 CIE 无图提示词

#### 常见问题

Q: 为什么生成的描述与有图模式不同？
A: 系统针对有图和无图场景使用不同的提示词，生成风格有所差异。

### 场景：AI 生成历史活动描述

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团主理人 | ✓ | 拥有群组内全部管理权限 |
| 社团管理员 | ✓ | 可为管理的群组生成活动描述 |
| 社区管理员 | ✓ | 拥有租户级管理权限 |

#### 操作入口

群组首页 → 选择群组 → 补充历史活动 → 点击「AI 生成描述」按钮

#### 操作流程

1. 进入补充历史活动页面，填写活动标题和描述（至少一项）
2. 点击「AI 生成描述」按钮
3. 系统根据标题和描述生成活动总结文案
4. 生成完成后，文案将自动填充到描述输入框

#### 限制与约束

- 标题和描述至少填写一项，否则无法生成
- 生成结果基于当前激活的 CE 描述提示词
- 历史活动不可报名或打卡，仅用于社团历程展示

#### 常见问题

Q: 为什么历史活动没有海报图片选项？
A: 历史活动通常补充过往记录，系统针对纯文本场景优化了生成效果。

### 场景：提示词管理（平台管理员）

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社区管理员 | ✓ | 拥有租户级管理权限，可管理所有提示词 |
| 社团主理人 | ✗ | 无权限管理提示词 |
| 社团管理员 | ✗ | 无权限管理提示词 |

#### 操作入口

管理后台 → AI 功能管理 → 提示词管理

#### 操作流程

**查看提示词列表**
1. 进入提示词管理页面
2. 选择提示词类型标签页：「CIE有图」「CIE无图」「CE无图」
3. 页面显示该类型下所有已保存的提示词

**新建提示词**
1. 在提示词输入框中输入提示词内容
2. 点击「保存」按钮
3. 在弹窗中输入提示词名称
4. 确认保存后，系统提示是否立即启用该提示词

**测试提示词**
1. 在提示词输入框中输入提示词内容
2. 对于 CIE 有图类型，选择一张测试图片
3. 填写测试标题和描述
4. 点击「测试」按钮
5. 页面下方显示「提示词返回」区域，实时展示生成结果

**激活提示词**
1. 在历史提示词列表中找到目标提示词
2. 点击「点击开启」按钮
3. 系统提示激活成功，该提示词状态变为「已开启」
4. 同类型下其他提示词自动关闭

**测试历史提示词**
1. 在历史提示词列表中找到目标提示词
2. 点击「测试」按钮
3. 系统将该提示词内容填入输入框并自动执行测试

#### 限制与约束

- 同类型提示词仅有一个可处于激活状态
- 提示词名称不可为空
- 提示词内容不可为空
- 激活操作为即时生效

#### 常见问题

Q: 为什么保存时提示需要输入名称？
A: 每个提示词必须有唯一名称便于识别和管理。

Q: 激活新提示词后，之前生成的活动描述会改变吗？
A: 不会，已生成的描述不受影响，仅后续新生成的描述使用新提示词。

Q: 测试时提示「请输入提示词」？
A: 请先在输入框中输入提示词内容再进行测试。

Q: CIE 有图测试时提示「请选择图片」？
A: 请选择至少一张图片用于海报识别测试。

Q: CIE 无图或 CE 测试时提示「请输入标题和描述」？
A: 无图模式需要标题和描述作为生成依据，至少填写一项。

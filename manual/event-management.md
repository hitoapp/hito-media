# 活动管理

## 概述

活动管理是喜多平台中围绕社团活动的创建、编辑、审核和附件管理的核心模块。该模块支持两种活动类型：普通活动（CIE，支持报名和打卡签到）和历史活动（CE，用于补充社团历程记录）。社团管理员可以创建、编辑、删除活动，管理活动参与人和附件，查看草稿箱，以及在开启审核功能时提交活动供管理员审核。

活动管理覆盖从活动创建到发布、从报名到签到的完整生命周期，是社团日常运营的重要工具。

## 核心概念

- **普通活动（CIE）**：支持用户报名和打卡签到的活动类型，包含报名设置、打卡设置、收费设置等功能，适用于需要用户参与和签到的场景。
- **历史活动（CE）**：由社团管理员手动补充的历史活动记录，不支持报名和打卡，一般仅用于社团历程展示。
- **活动草稿箱**：保存尚未发布的活动草稿，可随时编辑并发布。
- **活动审核**：当租户开启审核功能后，新创建或修改的活动需经审核通过后才能正式发布。
- **活动附件**：活动可附带文件资料（如图片、文档等），支持设置可见范围。
- **参与人**：活动的参与者记录，包括通过报名加入的用户和由管理员手动添加的成员。
- **打卡**：用户在活动时间范围内完成签到签退的行为，支持定位打卡和仅现场打卡两种模式。

## 操作指南

### 场景：创建活动（统一入口）

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团主理人（CO） | ✓ | 拥有社团内全部管理权限 |
| 社团管理员（CA） | ✓ | 可创建活动，创建者默认成为该活动的活动管理员 |
| 社区管理员（TA） | ✓ | 跨社团管理权限 |

#### 操作入口

社群首页 → 点击右上角菜单按钮 → 在菜单中选择创建活动入口

#### 操作流程

1. 进入创建活动页面后，首先选择活动类型：
   - 创建普通活动（CIE）：包含「基本信息」和「报名打卡」两个步骤
   - 补充历史活动（CE）：仅包含「基本信息」一个步骤

2. **填写基本信息**：
   - 上传活动图片（最多12张，支持拖拽排序），可勾选「海报」选项将第一张图设为海报
   - 输入活动名称（必填）
   - 填写活动描述（可使用AI帮写功能，系统将根据图片和标题自动生成描述）
   - 选择活动开始时间和结束时间（必填，结束时间不能早于开始时间）
   - 选择活动地址（可选，若开启定位打卡则地址将与打卡地点保持一致）
   - 开启评论区（可选，用户可在活动页面发表评论）

3. **配置报名打卡**（仅普通活动）：
   - **报名设置**：
     - 开启报名后，设置报名开始和结束时间
     - 可设置报名人数限制（大于0的整数）
     - 可设置报名成功后展示的群二维码和提示文字
     - 可开启活动收费（需联系喜多管理员开通），设置收费金额，可设置会员免费
     - 可设置活动问卷（报名时填写）
   - **打卡设置**：
     - 设置签到开始和结束时间
     - 选择活动地点
     - 开启位置打卡后，用户需在指定范围内才能签到，可调整打卡范围（100米至1000米）
     - 可开启签退功能，设置签退时间
     - 可开启NFC打卡（需社团配置支持）
     - 可开启仅现场签到（用户只能通过喜多打卡贴或亮码签二维码签到）

4. 点击「立即发布」提交活动，或点击「存草稿」保存为草稿

#### 限制与约束

- 活动名称为必填项
- 活动开始时间不能晚于结束时间
- 报名开始时间不能晚于报名结束时间
- 签到开始时间不能晚于签到结束时间
- 若开启位置打卡，必须选择活动地点
- 开启报名和打卡至少设置其中一项
- 收费金额不能超过社团配置的最大收费金额
- 活动图片最多12张，图片会自动压缩上传

#### 常见问题

Q: 为什么提示「请输入事件名称」？
A: 活动名称为必填项，请填写后再提交。

Q: 为什么提示「请选择事件日期」？
A: 活动开始时间是必填项，请选择后再提交。

Q: 为什么提示「请进行报名或者打卡设置」？
A: 普通活动（CIE）需要至少开启报名或打卡其中一项功能。

Q: 为什么提示「收费金额不能大于XX元」？
A: 收费金额受社团配置限制，不能超过社团允许的最大收费金额。

Q: 为什么提交后提示「活动已创建，问卷保存失败」？
A: 活动已成功创建，但关联问卷保存失败，可在活动设置中重新配置问卷。

### 场景：编辑活动

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团主理人（CO） | ✓ | 可编辑社团内所有活动 |
| 社团管理员（CA） | 仅自己创建的 | 只能编辑自己创建的活动 |
| 社区管理员（TA） | ✓ | 跨社团管理权限 |

#### 操作入口

社群首页 → 点击具体活动进入活动详情页 → 点击设置按钮 → 选择编辑活动

#### 操作流程

1. 进入活动编辑页面，页面会加载当前活动的已有信息
2. 修改需要变更的内容（基本信息或报名打卡设置）
3. 注意：若活动已开启收费，收费金额不可修改
4. 注意：已过时间的时间设置项会自动置灰不可修改
5. 点击「保存修改」提交变更

#### 限制与约束

- 编辑模式下不可切换所属社团
- 活动已开启收费时，收费金额不可修改
- 已过的时间设置项自动锁定不可修改
- 若租户开启了审核功能，已上线的活动修改后需重新审核

#### 常见问题

Q: 为什么某些时间选项无法点击？
A: 该时间已过，系统自动锁定不可修改。

Q: 编辑后活动需要重新审核吗？
A: 如果租户开启了审核功能且活动已上线，修改后需要重新提交审核。

### 场景：删除活动

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团主理人（CO） | ✓ | 可删除社团内所有活动 |
| 社团管理员（CA） | 仅自己创建的 | 只能删除自己创建的活动 |
| 社区管理员（TA） | ✓ | 跨社团管理权限 |

#### 操作入口

社群首页 → 点击具体活动进入活动详情页 → 点击设置按钮 → 选择删除活动

#### 操作流程

1. 在活动详情页点击删除按钮
2. 系统弹出确认对话框，确认删除后活动将被永久删除

#### 限制与约束

- 若活动存在已支付且未退款的订单，则不可删除
- 删除活动后，活动关联的参与人记录将被清理

#### 常见问题

Q: 为什么无法删除活动？
A: 如果活动存在已支付且未退款的订单，则无法删除。请先处理相关订单。

### 场景：活动草稿箱

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团主理人（CO） | ✓ | 可查看和管理社团内所有草稿 |
| 社团管理员（CA） | ✓ | 可查看和管理自己保存的草稿 |
| 社区管理员（TA） | ✓ | 跨社团管理权限 |

#### 操作入口

社群首页 → 点击右上角菜单按钮 → 选择「草稿箱」

#### 操作流程

1. 进入草稿箱页面，查看所有保存的草稿活动
2. 点击任意草稿进入编辑页面
3. 修改内容后可选择「存草稿」继续保存，或「立即发布」发布活动
4. 支持下拉刷新和上拉加载更多

#### 限制与约束

- 草稿箱按社团维度展示，仅显示当前社团的草稿
- 草稿可随时编辑或发布

#### 常见问题

Q: 草稿和正式活动有什么区别？
A: 草稿是保存但未发布的活动，不会对外展示，可随时编辑或发布。

### 场景：活动参与人管理

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团主理人（CO） | ✓ | 可管理所有活动的参与人 |
| 社团管理员（CA） | 仅自己创建的 | 只能管理自己创建的活动的参与人 |
| 社区管理员（TA） | ✓ | 跨社团管理权限 |

#### 操作入口

社群首页 → 点击具体活动进入活动详情页 → 进入参与人管理页面

#### 操作流程

1. 在创建活动时，可通过「选择成员」标签页选择活动参与成员
2. 支持搜索成员姓名或手机号快速定位
3. 选中成员后可填写每位成员的分工描述
4. 点击「填写分工/描述」可批量编辑已选成员的分工
5. 支持创建待绑定成员（尚未注册喜多的人员）

#### 限制与约束

- 参与人列表按成员维度管理，支持增删操作
- 删除参与人时需确认，已报名或已打卡的参与人不会被直接删除

#### 常见问题

Q: 如何为活动添加尚未加入社团的人员？
A: 可通过「创建待绑定成员」功能创建临时成员，待其注册后自动关联。

### 场景：活动附件管理

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团主理人（CO） | ✓ | 可管理所有活动的附件 |
| 社团管理员（CA） | ✓ | 可管理活动附件 |
| 社区管理员（TA） | ✓ | 跨社团管理权限 |

#### 操作入口

社群首页 → 点击具体活动进入活动详情页 → 点击附件管理入口

#### 操作流程

1. 进入附件管理页面，查看已上传的附件列表
2. 点击「上传附件」按钮，选择「微信文件」或「聊天图片」
3. 选择文件后自动上传，上传成功后可修改文件名
4. 点击附件右侧的可见性标签，可切换可见范围：
   - 成员可见：仅社团成员可查看和下载
   - 参与人可见：仅活动参与人可查看和下载
   - 任何人可见：所有人可查看和下载
5. 长按附件可拖拽调整显示顺序
6. 点击附件右上角的删除按钮可删除附件
7. 完成设置后点击「提交附件」保存

#### 限制与约束

- 每个活动最多上传8个附件
- 单个文件大小不超过20MB
- 支持的文件格式：jpg、jpeg、png、gif、bmp、webp、pdf、doc、docx、xls、xlsx、ppt、pptx、txt、zip、rar、7z
- 文件名不能为空，若清空将自动恢复为「未命名」

#### 常见问题

Q: 为什么上传失败？
A: 请检查文件格式是否支持、文件大小是否超过20MB限制。

Q: 如何修改附件的可见范围？
A: 点击附件下方的可见性标签（成员可见/参与人可见/任何人可见），在弹出的选项中选择新的可见范围。

Q: 电脑端可以上传附件吗？
A: 电脑端该功能暂不支持，建议在手机端操作。

### 场景：活动附件下载

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团主理人（CO） | ✓ | 根据附件可见范围判断 |
| 社团管理员（CA） | ✓ | 根据附件可见范围判断 |
| 普通成员/参与人 | ✓ | 根据附件可见范围判断 |

#### 操作入口

活动详情页 → 点击附件列表中的某个附件

#### 操作流程

1. 进入附件下载页面，显示文件名和文件大小
2. 点击「下载文件」按钮开始下载
3. 下载完成后：
   - 手机端：可「查看文件」或「分享给好友」
   - 电脑端：可「查看文件」或「保存到本地」
4. 支持的文件类型可直接预览（图片、文档等）

#### 限制与约束

- 下载的文件会保存在本地存储中
- 已下载的文件再次进入时会自动显示「已下载」状态

#### 常见问题

Q: 为什么提示「下载失败，请重试」？
A: 可能是网络不稳定或文件链接已过期，请检查网络后重试。

Q: 为什么提示「无法打开此文件」？
A: 手机端不支持预览该文件格式，可尝试分享给好友后通过其他应用打开。

### 场景：活动审核流程

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社区管理员（TA） | ✓ | 拥有审核权限，可审核所有活动 |
| 社团主理人（CO） | ✓ | 可查看本社团活动审核状态和审核记录 |
| 社团管理员（CA） | ✓ | 可查看自己提交的活动审核状态和审核记录 |

#### 操作入口

社群首页 → 点击右上角菜单按钮 → 选择「活动审核」

#### 操作流程

1. 进入活动审核页面，顶部显示「全部」「待审核」「已通过」「已拒绝」四个标签页
2. 点击任意审核记录查看详情
3. 在审核详情页可查看活动完整信息
4. TA角色可对活动进行通过或拒绝操作，并填写审核意见

#### 限制与约束

- 仅租户配置开启审核功能时，活动创建和修改需要审核
- 草稿活动不需要审核，直接保存
- 社团主理人可查看本社团全部审核记录，社团管理员仅查看自己提交的
- 审核通过后活动正式发布上线

#### 常见问题

Q: 为什么创建活动后没有立即显示？
A: 如果租户开启了审核功能，活动需经审核通过后才会正式发布。

Q: 活动被拒绝后怎么办？
A: 可根据审核意见修改活动内容后重新提交审核。

Q: 草稿需要审核吗？
A: 不需要，草稿保存后不会对外展示，无需审核。

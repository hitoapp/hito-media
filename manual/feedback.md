# 反馈系统

## 概述

反馈系统是喜多小程序中用于收集用户意见和问题的重要功能。通过该功能，用户可以向平台提交功能建议、BUG反馈或其他意见，帮助喜多团队持续改进产品体验。每一条反馈都会被认真对待并积极跟进处理。

用户还可以选择是否允许管理员针对反馈内容进行回访，以便更深入地了解问题详情。系统支持上传图片附件，方便用户直观地展示问题或建议。

本功能面向所有已登录的喜多用户，无论您是普通用户还是管理员，都可以使用反馈功能。

## 核心概念

- 反馈类型：分为"功能建议"、"BUG反馈"和"其他"三类，用于对反馈内容进行分类
- 反馈标题：简要描述反馈内容的标题，最多30个字符
- 反馈描述：详细描述问题或建议的内容，最多1000个字符
- 图片附件：支持上传最多9张图片，用于补充说明反馈内容
- 回访授权：用户可选择是否允许管理员通过联系方式进行回访

## 操作指南

### 场景：提交反馈

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✓ | 所有已登录用户均可提交反馈 |
| 社区管理员 | ✓ | 所有已登录用户均可提交反馈 |
| 社团主理人 | ✓ | 所有已登录用户均可提交反馈 |
| 社团管理员 | ✓ | 所有已登录用户均可提交反馈 |

#### 操作入口

个人中心 → 点击右上角菜单图标 → 意见反馈

#### 操作流程

1. 进入意见反馈页面后，首先阅读页面顶部的提示信息
2. 点击"反馈类型"选择框，从弹出的选项中选择合适的反馈类型（功能建议、BUG反馈或其他）
3. 在"反馈标题"输入框中输入简要的标题描述
4. 在"请详细描述您的问题或建议"文本框中输入详细的内容描述
5. 如需上传图片，点击图片上传区域，从相册中选择或拍摄照片（最多9张）
6. 如需管理员回访，打开"我们是否可以针对该问题回访您"开关
7. 当打开回访开关后，在"您的联系方式"输入框中输入微信号或联系电话
8. 确认信息无误后，点击页面底部的"提交反馈"按钮
9. 系统提示"提交成功，感谢您的反馈"后自动返回上一页

#### 限制与约束

- 反馈类型、标题和描述为必填项
- 标题最多30个字符，描述最多1000个字符
- 图片最多上传9张，单张图片会自动压缩
- 如开启回访开关，联系方式为必填项，最多72个字符
- 图片支持常见格式，上传后会自动压缩处理

#### 常见问题

Q: 为什么无法提交反馈？
A: 请检查是否已填写反馈类型、标题和描述，这三项为必填项。如开启了回访功能，请确保已填写联系方式。

Q: 上传图片失败怎么办？
A: 请检查网络连接是否正常，图片格式是否支持。如遇问题可尝试重新选择图片。

Q: 提交反馈后如何知道处理进度？
A: 目前反馈系统暂不支持查看处理进度，但您的反馈会被认真记录和处理。如需了解进度，可通过回访功能留下联系方式。

Q: 可以修改已提交的反馈吗？
A: 目前反馈系统不支持修改已提交的内容，如需补充信息可重新提交新的反馈。

Q: 如何直接联系管理员？
A: 在意见反馈页面顶部，点击"直接联系管理员（点击私信）"链接，即可与管理员进行私信沟通。

### 场景：联系管理员

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✓ | 所有已登录用户均可联系管理员 |
| 社区管理员 | ✓ | 所有已登录用户均可联系管理员 |
| 社团主理人 | ✓ | 所有已登录用户均可联系管理员 |
| 社团管理员 | ✓ | 所有已登录用户均可联系管理员 |

#### 操作入口

个人中心 → 点击右上角菜单图标 → 意见反馈 → 点击"直接联系管理员（点击私信）"

#### 操作流程

1. 进入意见反馈页面
2. 在页面顶部的提示信息中，找到"直接联系管理员（点击私信）"链接
3. 点击该链接，系统将自动跳转到与管理员的私信聊天界面
4. 在聊天界面中输入消息内容并发送即可

#### 限制与约束

- 不能给自己发送私信
- 需要已登录状态才能使用私信功能

#### 常见问题

Q: 为什么点击"直接联系管理员"没有反应？
A: 请检查是否已登录，如已登录仍无法使用，请确认当前账号不是管理员本人（不能给自己发送私信）。

Q: 私信消息发送后管理员能看到吗？
A: 是的，管理员会收到您的私信消息并会及时回复。

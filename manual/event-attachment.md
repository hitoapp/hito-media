# 活动附件

## 概述

活动附件是喜多为活动管理者提供的文件管理功能，允许群组管理员和群组主理人在活动中上传和管理附件文件，供参与人或群组成员下载使用。

该功能解决了活动组织者需要向参与者分发资料的场景需求，例如活动手册、签到表、演示文稿、参考文件等。通过设置不同的可见性，管理者可以灵活控制谁能下载这些附件。

目标用户包括群组主理人、群组管理员，以及所有可以查看活动并下载附件的参与人和成员。

## 核心概念

- **活动附件**：挂载在某个活动下的文件，可设置可见性并供指定用户下载
- **可见性**：控制附件能被哪些人看到和下载，分为三种类型
  - **成员可见**：仅群组成员可以下载
  - **参与人可见**：群组成员和该活动的参与人都可以下载
  - **任何人可见**：所有能看到该活动的人都可以下载
- **文件大小限制**：单个附件最大支持 20MB
- **附件数量限制**：每个活动最多可上传 8 个附件

## 操作指南

### 场景：上传活动附件

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可管理群组内所有活动的附件 |
| 群组管理员 | ✓ | 可上传和管理活动附件 |

#### 操作入口

活动详情页 → 点击右上角设置按钮 → 活动附件

#### 操作流程

1. 进入活动详情页，点击右上角设置按钮（齿轮图标）
2. 在弹出的设置面板中，点击"活动附件"
3. 进入活动附件管理页面，点击"上传附件"按钮
4. 选择要上传的文件来源：
   - **微信文件**：从微信聊天记录中选择文件
   - **聊天图片**：从微信聊天记录中选择图片
5. 选择文件后自动开始上传，上传成功后会在列表中显示
6. 上传完成后，可点击文件名修改名称，或点击可见性标签调整可见范围
7. 所有设置完成后，点击底部"提交附件"按钮保存

#### 限制与约束

- 每个活动最多上传 8 个附件
- 单个文件大小不能超过 20MB
- 支持的文件格式：
  - 图片：JPG、JPEG、PNG、GIF、BMP、WEBP
  - 文档：PDF、DOC、DOCX、XLS、XLSX、PPT、PPTX、TXT
  - 压缩包：ZIP、RAR、7Z
- 电脑端仅支持微信文件选择，不支持图片选择

#### 常见问题

Q: 为什么无法上传文件？
A: 请检查文件是否超过 20MB 大小限制，或文件格式是否支持。支持的格式包括常见图片、文档和压缩包格式。

Q: 上传过程中提示"上传失败"怎么办？
A: 可能是网络不稳定导致，建议检查网络连接后重新尝试上传。

Q: 电脑端为什么不能选择图片？
A: 电脑端微信小程序暂不支持选择聊天图片功能，建议在手机端操作。

### 场景：修改附件文件名

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可修改所有附件的文件名 |
| 群组管理员 | ✓ | 可修改所有附件的文件名 |

#### 操作入口

活动详情页 → 点击右上角设置按钮 → 活动附件

#### 操作流程

1. 进入活动附件管理页面
2. 在附件列表中，直接点击文件名输入框
3. 输入新的文件名（不含扩展名）
4. 输入完成后点击其他区域或按回车确认
5. 点击"提交附件"保存修改

#### 限制与约束

- 文件名不能为空，若清空后失焦会自动恢复为"未命名"
- 文件名最长 50 个字符
- 文件扩展名不可修改，仅可编辑文件名部分

#### 常见问题

Q: 为什么修改文件名后显示"未命名"？
A: 文件名不能为空，如果清空文件名后失焦，系统会自动恢复为"未命名"。

### 场景：调整附件可见性

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可调整所有附件的可见性 |
| 群组管理员 | ✓ | 可调整所有附件的可见性 |

#### 操作入口

活动详情页 → 点击右上角设置按钮 → 活动附件

#### 操作流程

1. 进入活动附件管理页面
2. 点击附件右侧的可见性标签（如"参与人可见"）
3. 在弹出的选择面板中选择新的可见性：
   - **成员可见**：仅群组成员可下载
   - **参与人可见**：群组成员和活动参与人可下载
   - **任何人可见**：所有能看到活动的人都可下载
4. 选择后标签会更新显示
5. 点击"提交附件"保存修改

#### 限制与约束

- 可见性修改后需点击"提交附件"才会生效
- 上传第一个附件时会自动弹出可见性设置提示

#### 常见问题

Q: 设置"任何人可见"后谁可以下载？
A: 所有能看到该活动页面的用户都可以下载该附件，无需是群组成员或活动参与人。

### 场景：删除附件

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可删除所有附件 |
| 群组管理员 | ✓ | 可删除所有附件 |

#### 操作入口

活动详情页 → 点击右上角设置按钮 → 活动附件

#### 操作流程

1. 进入活动附件管理页面
2. 在附件列表中，点击附件右上角的关闭按钮（×）
3. 在弹出的确认对话框中点击"确定"
4. 附件从列表中移除
5. 点击"提交附件"保存修改

#### 限制与约束

- 删除后需点击"提交附件"才会生效
- 删除操作不可撤销，请谨慎操作

#### 常见问题

Q: 删除附件后还能恢复吗？
A: 删除操作不可撤销，提交后附件将被永久移除。如需恢复，需要重新上传。

### 场景：调整附件顺序

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可调整所有附件的顺序 |
| 群组管理员 | ✓ | 可调整所有附件的顺序 |

#### 操作入口

活动详情页 → 点击右上角设置按钮 → 活动附件

#### 操作流程

1. 进入活动附件管理页面
2. 长按要移动的附件，直到振动反馈
3. 拖动附件到目标位置
4. 松手后附件会自动调整到新位置
5. 点击"提交附件"保存修改

#### 限制与约束

- 拖拽排序仅在手机端支持
- 电脑端暂不支持拖拽排序功能

#### 常见问题

Q: 拖拽时附件没有移动怎么办？
A: 请确保长按时间足够（约 0.5 秒），收到振动反馈后再拖动。

### 场景：下载活动附件

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可下载所有可见附件 |
| 群组管理员 | ✓ | 可下载所有可见附件 |
| 群组成员 | ✓ | 可下载"成员可见"及以上的附件 |
| 活动参与人 | ✓ | 可下载"参与人可见"及以上的附件 |
| 其他用户 | 仅公开 | 仅可下载"任何人可见"的附件 |

#### 操作入口

活动详情页 → 点击附件 → 下载附件

#### 操作流程

1. 在活动详情页找到附件区域，点击要下载的附件
2. 进入附件下载页面，查看文件信息
3. 点击"下载文件"按钮开始下载
4. 下载完成后，根据文件类型可选择：
   - **查看文件/图片**：直接在小程序内预览
   - **分享给好友**：将文件分享给微信好友（手机端）
   - **保存到本地**：保存到电脑本地磁盘（电脑端）

#### 限制与约束

- 图片和常见文档格式（PDF、Word、Excel、PPT）支持在线预览
- 其他格式文件仅支持下载和分享
- 电脑端下载后会自动弹出保存对话框

#### 常见问题

Q: 下载时提示"下载失败"怎么办？
A: 请检查网络连接，然后重试。如果持续失败，可能是文件暂时不可用，请稍后再试。

Q: 为什么有些附件看不到或无法下载？
A: 附件的可见性由活动管理者设置。如果您不在允许下载的用户范围内，将无法看到或下载该附件。

Q: 下载的文件在哪里找到？
A: 手机端下载的文件在小程序内可直接查看；电脑端下载的文件会保存到本地磁盘，可通过"查看文件"打开。

# AI 问一问

## 概述

AI 问一问是喜多小程序内的智能帮助入口。它可以根据已有的用户帮助内容，回答活动创建、活动附件、分享统计等产品使用问题，帮助用户更快找到操作方法。

用户可以直接输入问题，也可以从页面提供的常用问题中选择。回答会在对话中逐步展示；已注册用户的历史提问可在下次进入时继续查看，并可按需清除。

## 核心概念

- 问一问：小程序中的智能帮助入口，显示在支持该功能的页面右上角。
- 用户帮助：问一问回答问题时所参考的喜多使用说明内容。
- 常用问题：首次进入或清空会话后显示的快捷提问选项。
- 历史对话：当前用户此前提出的问题及对应回答。
- 帮助对话：全局管理员查看用户提问与回答的管理记录。

## 操作指南

### 场景：打开 AI 问一问并提出问题

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 全局管理员 | ✓ | 完成注册且问一问入口可见时可使用。 |
| 租户管理员 | ✓ | 完成注册且问一问入口可见时可使用。 |
| 群组主理人 | ✓ | 完成注册且问一问入口可见时可使用。 |
| 群组管理员 | ✓ | 完成注册且问一问入口可见时可使用。 |
| 普通用户 | ✓ | 完成注册且问一问入口可见时可使用。 |

#### 操作入口

社区首页、活动详情页或创建活动页 → 右上角「问一问」

#### 操作流程

1. 在社区首页、活动详情页或创建活动页右上角点击「问一问」。也可从「我的」页面打开更多菜单，选择「帮助中心」。
2. 在输入框中输入产品使用问题，点击「发送」或使用键盘发送；每次问题最多可输入 200 个字符。
3. 也可以直接点击常用问题，例如「如何创建活动？」。
4. 等待回答逐步显示。回答中包含列表或表格时，会保留相应的阅读格式。

#### 限制与约束

- 问一问入口仅在智能帮助服务可用时显示。
- 发起提问前需要完成注册；未完成注册时，系统会先打开注册提示。
- 提问内容不能为空。
- 系统正在回答时，不能同时发送下一条问题；请等待当前回答完成。
- 首次成功提问后，常用问题区会自动收起。

#### 常见问题

Q: 为什么页面上没有「问一问」？
A: 该入口只会在智能帮助服务可用时显示。可稍后重试，或从「我的 → 更多菜单 → 帮助中心」进入。

Q: 为什么点击发送后没有开始提问？
A: 请确认已完成注册且输入框中有内容；如果系统正在回答，请等待回答结束后再发送下一条问题。

Q: 为什么会弹出注册提示？
A: AI 问一问需要完成注册后才能发送问题。

### 场景：查看历史回答和清除会话

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 全局管理员 | ✓ | 已注册且存在个人身份时可查看和清除自己的会话。 |
| 租户管理员 | ✓ | 已注册且存在个人身份时可查看和清除自己的会话。 |
| 群组主理人 | ✓ | 已注册且存在个人身份时可查看和清除自己的会话。 |
| 群组管理员 | ✓ | 已注册且存在个人身份时可查看和清除自己的会话。 |
| 普通用户 | ✓ | 已注册且存在个人身份时可查看和清除自己的会话。 |

#### 操作入口

社区首页、活动详情页或创建活动页 → 右上角「问一问」

#### 操作流程

1. 打开 AI 问一问后，系统会自动加载当前用户此前的提问和回答。
2. 向上浏览对话内容，查看之前的问题和对应回答。
3. 如需重新开始，在页面右上角点击清除会话图标。
4. 在确认提示中选择「清除」。清除成功后，历史对话消失，常用问题会重新显示。

#### 限制与约束

- 仅显示和清除当前用户自己的帮助对话。
- 正在回答时不能清除会话，需要等待当前回答结束。
- 清除操作需要二次确认；确认后当前会话页面将恢复为空白状态。

#### 常见问题

Q: 为什么没有看到清除会话按钮？
A: 清除按钮只会在当前用户具备个人身份信息时显示。

Q: 为什么无法清除会话？
A: 系统正在回答时不能清除。请等待回答结束后再操作；若仍失败，请稍后重试。

Q: 清除后还能找回之前的对话吗？
A: 清除后页面会移除当前帮助会话并恢复常用问题入口，请在清除前确认不再需要这些内容。

### 场景：全局管理员更新帮助内容和查看帮助对话

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 全局管理员 | ✓ | 可进入系统管理并更新帮助内容、查看帮助对话。 |
| 租户管理员 | ✗ | 没有系统管理入口。 |
| 群组主理人 | ✗ | 没有系统管理入口。 |
| 群组管理员 | ✗ | 没有系统管理入口。 |
| 普通用户 | ✗ | 没有系统管理入口。 |

#### 操作入口

我的 → 更多菜单 → 系统管理 → 管理员菜单

#### 操作流程

1. 全局管理员进入「管理员菜单」。
2. 点击「更新帮助」，在确认提示中选择「更新」，使最新的用户帮助内容用于后续问答。
3. 点击「帮助对话」查看用户提问列表；下拉可刷新，滚动到底部可继续加载更多记录。
4. 点击某一条记录，查看用户、提问时间、问题和回答；需要时可复制用户标识。

#### 限制与约束

- 「更新帮助」和「帮助对话」仅在全局管理员的管理员菜单中提供。
- 更新帮助需要二次确认。
- 帮助对话列表每次加载 20 条记录，全部加载完成后会显示提示。
- 没有帮助对话时，列表会显示「暂无帮助对话」。

#### 常见问题

Q: 为什么看不到「系统管理」？
A: 「系统管理」仅面向全局管理员显示；请确认当前账号是否具备全局管理员权限。

Q: 为什么帮助对话列表为空？
A: 当前尚未记录用户的帮助提问，或已没有可继续加载的记录。

Q: 为什么更新帮助后没有立即看到变化？
A: 请等待更新完成提示出现后，再重新发起问题以获取基于最新帮助内容的回答。

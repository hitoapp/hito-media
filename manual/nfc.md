# NFC 功能

## 概述

NFC 功能是喜多平台提供的一种便捷签到方式。通过将实体 NFC 打卡贴与群组或活动关联，参与者只需用手机触碰打卡贴，即可快速跳转到对应的群组页面或活动详情页，实现"碰一碰"签到体验。

本功能主要面向社区管理员（TA）和社团管理员（CA），由 TA 负责为群组创建 NFC 打卡贴，CA 负责将 NFC 绑定到具体活动。普通用户只需触碰打卡贴即可完成跳转。

## 核心概念

- **NFC 打卡贴**：一种实体 NFC 标签，由 TA 创建后与群组关联，用户触碰后可跳转到指定页面
- **NFC Scheme**：NFC 打卡贴的配置信息，包含跳转路径和参数，用于写入实体标签
- **跳转类型**：NFC 打卡贴支持两种跳转目标——群组首页或活动详情页
- **绑定/解绑**：将 NFC 打卡贴的跳转目标从群组首页切换到某个活动，或从活动切换回群组首页

## 操作指南

### 场景：TA 为群组创建 NFC 打卡贴

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社区管理员（TA） | ✓ | 可以为管辖范围内的群组创建 NFC |
| 社团主理人（CO） | ✗ | 无权创建 NFC |
| 社团管理员（CA） | ✗ | 无权创建 NFC |
| 普通用户 | ✗ | 无权创建 NFC |

#### 操作入口

社区管理后台 → 选择群组 → 群组管理页面

#### 操作流程

1. 进入社区管理后台，找到需要创建 NFC 的群组
2. 点击进入群组管理页面
3. 在群组功能配置区域，找到"NFC打卡贴"选项
4. 点击"点击创建"按钮
5. 系统提示"创建成功"
6. 长按已创建的 NFC 状态区域，可复制 NFC Scheme 信息（用于写入实体标签）

#### 限制与约束

- 每个群组只能创建一个 NFC 打卡贴，已创建的群组无法重复创建
- 创建后无法删除，只能使用
- NFC Scheme 需要由专业人员写入实体 NFC 标签

#### 常见问题

Q: 为什么无法创建 NFC？
A: 该群组已经创建过 NFC 打卡贴，每个群组仅支持创建一个。

Q: NFC Scheme 是什么？
A: NFC Scheme 是 NFC 打卡贴的配置信息，需要由专业人员使用 NFC 写入工具将此信息写入实体标签。

Q: 创建后如何获取 NFC Scheme？
A: 在群组管理页面，长按"NFC打卡贴"区域即可复制 Scheme 信息。

### 场景：NFC 跳转（用户触碰打卡贴）

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社区管理员（TA） | ✓ | 触碰后正常跳转 |
| 社团主理人（CO） | ✓ | 触碰后正常跳转 |
| 社团管理员（CA） | ✓ | 触碰后正常跳转 |
| 普通用户 | ✓ | 触碰后正常跳转 |

#### 操作入口

手机触碰已配置的 NFC 打卡贴

#### 操作流程

1. 确保手机已开启 NFC 功能
2. 将手机背部靠近 NFC 打卡贴
3. 手机自动识别 NFC 标签
4. 自动跳转到对应的群组页面或活动详情页
5. 完成跳转后可进行签到等操作

#### 限制与约束

- 手机必须支持 NFC 功能并已开启
- 需要在微信小程序内或通过微信扫码触发
- NFC 打卡贴必须已正确写入 Scheme 信息
- NFC 打卡贴必须已与群组关联

#### 常见问题

Q: 触碰 NFC 后没有反应？
A: 请检查手机是否支持 NFC 功能，以及是否已开启 NFC。同时确保在微信环境下触发。

Q: 触碰后跳转到错误的页面？
A: 请检查 NFC 打卡贴是否已正确绑定到目标群组或活动。如需修改跳转目标，请联系 CA 进行绑定/解绑操作。

Q: 跳转后显示空白页面？
A: 可能是网络问题或小程序版本过旧，请检查网络连接并更新小程序版本。

### 场景：CA 为活动绑定/解绑 NFC

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社区管理员（TA） | ✓ | 可以为任意活动绑定/解绑 |
| 社团主理人（CO） | ✓ | 可以为所在群组的活动绑定/解绑 |
| 社团管理员（CA） | ✓ | 可以为所在群组的活动绑定/解绑 |
| 普通用户 | ✗ | 无权操作 |

#### 操作入口

活动详情页 → 活动设置

#### 操作流程

1. 进入活动详情页
2. 点击进入活动设置页面
3. 在签到设置区域，找到"碰一碰签"选项
4. 点击开关按钮进行绑定或解绑操作
5. 系统弹出确认对话框
6. 确认操作后，系统提示"已开启碰一碰签"或"已关闭碰一碰签"

#### 限制与约束

- 该群组必须已创建 NFC 打卡贴才能进行绑定/解绑操作
- 同一时间只能有一个活动绑定 NFC，绑定新活动会自动解绑之前的活动
- 解绑后 NFC 将恢复跳转到群组首页

#### 常见问题

Q: 为什么看不到"碰一碰签"选项？
A: 该群组尚未创建 NFC 打卡贴，请联系社区管理员（TA）先创建 NFC。

Q: 绑定活动后，触碰 NFC 跳转到哪里？
A: 绑定后触碰 NFC 将直接跳转到该活动的详情页，方便参与者快速签到。

Q: 解绑后 NFC 跳转到哪里？
A: 解绑后触碰 NFC 将恢复跳转到群组首页。

Q: 可以同时绑定多个活动吗？
A: 不可以，同一时间只能绑定一个活动。绑定新活动会自动解绑之前的活动。

### 场景：在创建活动时绑定 NFC

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社区管理员（TA） | ✓ | 可以在创建活动时选择绑定 NFC |
| 社团主理人（CO） | ✓ | 可以在创建活动时选择绑定 NFC |
| 社团管理员（CA） | ✓ | 可以在创建活动时选择绑定 NFC |
| 普通用户 | ✗ | 无权创建活动 |

#### 操作入口

活动创建页面 → 签到设置

#### 操作流程

1. 进入活动创建页面
2. 填写活动基本信息
3. 进入签到设置区域
4. 找到"是否绑定喜多打卡贴"选项
5. 开启开关，表示该活动绑定 NFC
6. 完成活动创建后，NFC 将自动绑定到该活动

#### 限制与约束

- 该群组必须已创建 NFC 打卡贴才能看到绑定选项
- 绑定后，触碰 NFC 将跳转到该活动详情页
- 活动创建后仍可在活动设置中修改绑定状态

#### 常见问题

Q: 为什么看不到"是否绑定喜多打卡贴"选项？
A: 该群组尚未创建 NFC 打卡贴，请联系社区管理员（TA）先创建 NFC。

Q: 创建活动时忘记绑定 NFC，事后可以绑定吗？
A: 可以，在活动设置页面的"碰一碰签"选项中进行绑定操作。

Q: 绑定 NFC 后，活动发布需要审核吗？
A: 绑定 NFC 不影响活动发布流程，是否需要审核取决于群组的活动审核设置。

# 核心概念

## 概述

喜多（HITO）是一个面向私域活动管理的 SaaS 平台，旨在帮助社区组织者高效管理社团和活动。平台采用多租户隔离架构，确保不同社区之间的数据完全独立。

理解喜多的核心概念是高效使用平台的基础。本手册将详细介绍系统的组织架构、角色权限、活动分类等关键概念，帮助您快速上手并充分利用平台功能。

无论您是平台管理员、社团主理人还是普通成员，了解这些核心概念都将帮助您更好地参与和管理活动。

## 核心概念

### 组织架构

喜多采用三层组织架构，自顶向下依次为：

- **社区（Tenant）**：平台的最高层级组织单位，代表一个独立的运营主体。每个社区拥有独立的数据空间和管理权限，由社区管理员负责整体运营。
- **社团（Crowd）**：隶属于某个社区的次级组织，是活动的基本承载单位。每个社团由社团主理人创建和管理，可以创建和组织各类活动。
- **活动（Event）**：社团下开展的具体事件，分为打卡活动和历史活动两大类，是用户参与互动的核心载体。

### 角色权限

喜多定义了四级管理角色，权限自上而下递减：

- **全局管理员（GA）**：平台最高权限角色，可跨社区管理所有用户、社团和活动，处理平台级事务。
- **社区管理员（TA）**：社区级管理者，负责管理本社区内所有社团的创建审核、活动审核和运营监控。
- **社团主理人（CO）**：社团的创建者和拥有者，对社团拥有完整管理权限，包括成员管理、活动创建和渠道配置。
- **社团管理员（CA）**：由社团主理人授权的管理人员，可管理社团成员、创建活动，但权限受限于主理人的授权范围。

### 活动分类

- **打卡活动（CIE）**：支持用户报名、签到打卡的正式活动，适用于日常运营和用户参与场景。
- **历史活动（CE）**：由管理员手动补充的历史记录，不支持报名和打卡，主要用于展示社团发展历程和过往成就。

### 其他关键概念

- **关注（Subscribe）**：用户可关注感兴趣的社团，关注后该社团的新活动将出现在个人首页。
- **渠道（Channel）**：社团的分享入口，通过渠道码可快速访问社团或活动页面。
- **认证（Certified）**：社团完成官方认证后获得的标识，表示该社团已通过平台审核。

## 操作指南

### 场景：了解您在社团中的角色

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 全局管理员（GA） | ✓ | 可查看所有社团的角色信息 |
| 社区管理员（TA） | ✓ | 可查看本社区所有社团的角色信息 |
| 社团主理人（CO） | ✓ | 可查看本社团所有成员的角色信息 |
| 社团管理员（CA） | ✓ | 可查看本社团所有成员的角色信息 |
| 普通成员 | 仅自己 | 仅能查看自己的成员信息 |

#### 操作入口

社区首页 → 选择社团 → 点击右上角菜单

#### 操作流程

1. 进入社团首页后，点击右上角菜单按钮
2. 在弹出的菜单中查看您的头像和名称
3. 菜单中显示的功能项即为您当前角色可执行的操作

#### 限制与约束

- 菜单中显示的功能项根据您的角色动态变化
- 未登录用户仅能查看社团基本信息，无法访问管理功能

#### 常见问题

Q: 为什么我看不到「成员管理」功能？
A: 该功能仅对社团主理人和社团管理员开放，请确认您在该社团中具有管理权限。

Q: 如何查看我是否是社团主理人？
A: 进入社团菜单，如果可以看到「邀请管理员」功能，则您是该社团的主理人。

### 场景：区分打卡活动与历史活动

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 全局管理员（GA） | ✓ | 可管理所有类型的活动 |
| 社区管理员（TA） | ✓ | 可审核和管理本社区所有活动 |
| 社团主理人（CO） | ✓ | 可创建和管理本社团所有活动 |
| 社团管理员（CA） | ✓ | 可创建和管理自己创建的活动 |
| 普通成员 | 仅参与 | 可报名和打卡，不可创建活动 |

#### 操作入口

社区首页 → 选择社团 → 活动列表

#### 操作流程

1. 进入社团首页，查看活动列表
2. 打卡活动：显示报名按钮和打卡状态，支持用户参与互动
3. 历史活动：仅显示活动详情和参与记录，无报名入口

#### 限制与约束

- 打卡活动支持报名、签到、打卡等互动功能
- 历史活动仅用于展示，不支持报名和打卡操作
- 历史活动由管理员通过「补充历史活动」功能手动创建

#### 常见问题

Q: 为什么有些活动无法报名？
A: 该活动可能是历史活动（CE），历史活动仅用于记录和展示，不支持报名参与。

Q: 如何创建打卡活动？
A: 在社团菜单中选择「创建活动」，按提示填写活动信息即可创建打卡活动。

### 场景：理解关注与成员的区别

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 全局管理员（GA） | ✓ | 可管理所有关注和成员关系 |
| 社区管理员（TA） | ✓ | 可管理本社区所有关注和成员关系 |
| 社团主理人（CO） | ✓ | 可管理本社团所有关注和成员关系 |
| 社团管理员（CA） | ✓ | 可管理本社团成员 |
| 普通成员 | 自己 | 可关注或取消关注社团 |

#### 操作入口

社团首页 → 社团信息区域

#### 操作流程

1. 进入社团首页，查看社团信息区域
2. 点击「关注」按钮可关注该社团
3. 关注后，该社团的新活动将出现在您的个人首页
4. 成员身份需要通过申请并获得审核通过

#### 限制与约束

- 关注操作无需审核，立即生效
- 成为成员需要提交申请并经管理员审核
- 成员身份包含关注的所有功能

#### 常见问题

Q: 关注和加入社团有什么区别？
A: 关注是轻量级订阅，新活动会出现在个人首页；加入社团成为成员后，可参与社团管理和互动。

Q: 取消关注后会怎样？
A: 取消关注后，该社团的新活动将不再出现在您的个人首页。

### 场景：查看社团认证状态

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 全局管理员（GA） | ✓ | 可管理所有社团的认证状态 |
| 社区管理员（TA） | ✓ | 可管理本社区社团的认证状态 |
| 社团主理人（CO） | ✓ | 可查看本社团认证状态 |
| 社团管理员（CA） | ✓ | 可查看本社团认证状态 |
| 普通成员 | ✓ | 可查看社团认证状态 |

#### 操作入口

社团首页 → 社团名称旁的认证图标

#### 操作流程

1. 进入社团首页，查看社团名称
2. 名称旁显示认证图标，彩色表示已认证，灰色表示未认证
3. 点击图标可查看认证说明

#### 限制与约束

- 认证状态由平台管理员审核和管理
- 认证仅表示该社团已通过平台审核，不代表对社团内容的背书

#### 常见问题

Q: 认证图标是灰色的意味着什么？
A: 灰色图标表示该社团尚未完成认证，请注意甄别社团信息。

Q: 如何申请社团认证？
A: 社团认证由平台管理员发起，请联系所在社区的社区管理员咨询。

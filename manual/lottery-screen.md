# 抽奖大屏

## 概述

抽奖大屏用于在线下活动现场，通过 PC 浏览器集中展示参与名单、抽取过程、中奖结果和历轮记录，适合投放到电视、投影或会议室大屏。大屏是展示端：它会随现场抽奖进度实时变化，但不会在浏览器中创建轮次、开始抽取或公布结果。

活动管理员需要在喜多小程序中完成抽奖创建、轮次设置和大屏登录授权；抽奖嘉宾负责在小程序中开始和停止抽取。活动参与者也可扫描大屏的邀请码进入小程序参与抽奖。

## 核心概念

- 活动管理员：负责在小程序中创建和管理抽奖、配置轮次、指定抽奖嘉宾，并授权 PC 大屏登录。
- 抽奖嘉宾：由活动管理员指定，负责在小程序中开始和停止当前轮次的抽取。
- 大屏码：PC 浏览器打开抽奖大屏后生成的二维码，用于让活动管理员授权这台浏览器。
- 抽奖邀请码：大屏展示给现场参与者的二维码；参与者扫码后可进入该活动的抽奖流程。
- 轮次：一次抽奖设置，包含奖品名称、奖品数量和抽奖嘉宾。
- 候场：尚未准备抽取时的展示状态，大屏显示参与名单并等待下一步操作。
- 中奖揭晓：抽取完成后的展示状态，大屏突出展示本轮中奖人。

## 操作指南

### 场景：活动管理员授权 PC 浏览器登录抽奖大屏

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 全局管理员 | 仅作为本活动管理员时可执行 | 系统角色本身不代表已获得该活动的大屏授权权限。 |
| 租户管理员 | 仅作为本活动管理员时可执行 | 系统角色本身不代表已获得该活动的大屏授权权限。 |
| 群组主理人 | 仅作为本活动管理员时可执行 | 请以当前活动的管理员身份为准。 |
| 群组管理员 | 仅作为本活动管理员时可执行 | 请以当前活动的管理员身份为准。 |
| 普通用户 | ✗ | 不能授权 PC 大屏登录。 |

#### 操作入口

活动详情页 → 右上角控制面板 → 活动管理 → 开始抽奖 → 抽奖大屏

#### 操作流程

1. 活动管理员在喜多小程序中进入本活动的「开始抽奖」页面，点击「抽奖大屏」。
2. 页面弹出「使用抽奖大屏」提示。根据引导，先在电脑浏览器输入 `lottery.innosync.cn`。
3. 电脑浏览器显示「抽奖大屏」登录页和二维码后，回到小程序弹窗，点击「扫码登录」。
4. 使用小程序扫描电脑浏览器上的二维码，授权这台电脑登录本活动的抽奖大屏。
5. 小程序提示「授权成功，请查看大屏抽奖界面」后，电脑会自动进入抽奖大屏。
6. 保持电脑浏览器打开。后续在小程序中管理轮次和执行抽取时，大屏会自动同步现场状态。

#### 限制与约束

- 仅本活动的活动管理员可为 PC 浏览器授权。
- 大屏码有效期为 3 分钟，且仅可使用一次。
- 大屏码只能由生成该二维码时所用网络中的浏览器完成登录。若电脑切换网络，需要刷新页面重新生成二维码。
- 电脑端无法替代小程序进行轮次创建、准备、开始或开奖。

#### 常见问题

Q: 扫码后为什么不能授权？
A: 请确认当前小程序账号是本活动的活动管理员，并且扫描的是电脑端当前显示的有效二维码。

Q: 为什么提示大屏码已过期或已使用？
A: 返回电脑登录页点击「刷新」生成新的二维码，再使用小程序重新扫描。

Q: 为什么扫描后电脑仍停留在登录页？
A: 请确认小程序已出现授权成功提示，并保持电脑网络不变；若仍未进入，请在电脑端刷新二维码后重试。

### 场景：使用 PC 大屏展示现场抽奖过程

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 全局管理员 | ✓（使用已授权的浏览器） | 浏览器进入大屏后不再单独校验操作者的小程序角色。 |
| 租户管理员 | ✓（使用已授权的浏览器） | 浏览器进入大屏后不再单独校验操作者的小程序角色。 |
| 群组主理人 | ✓（使用已授权的浏览器） | 浏览器进入大屏后不再单独校验操作者的小程序角色。 |
| 群组管理员 | ✓（使用已授权的浏览器） | 浏览器进入大屏后不再单独校验操作者的小程序角色。 |
| 普通用户 | ✓（现场观看） | 可观看投放到电视或投影上的大屏，无需登录浏览器。 |

#### 操作入口

电脑浏览器 → 抽奖大屏登录成功 → 抽奖大屏首页

#### 操作流程

1. 登录成功后，大屏会加载当前活动的抽奖轮次和已加入的现场参与者。
2. 尚未准备轮次时，大屏显示完整参与名单，并提示等待活动管理员开启下一轮。
3. 活动管理员在小程序中点击「准备开始」后，大屏将名单展示为准备抽奖的状态。
4. 抽奖嘉宾在小程序中开始抽取后，大屏切换为抽取状态。
5. 抽取完成后，大屏展示本轮中奖人、庆祝效果和中奖标识；可点击「返回参与名单」查看全部参与者及本轮中奖标记。
6. 活动管理员在小程序中准备下一轮后，大屏会自动切换至新的轮次。

#### 限制与约束

- 大屏展示以小程序中的抽奖状态为准；浏览器端不提供开始或开奖控制。
- 若活动尚未创建抽奖，大屏会提示等待活动管理员创建抽奖。
- 若暂时没有参与者加入，大屏会提示等待参与者加入抽奖。
- 抽取前，未中奖的在线参与人数必须不少于本轮奖品数量；人数不足时，活动管理员无法在小程序中准备该轮。

#### 常见问题

Q: 为什么大屏没有显示抽奖球体？
A: 活动管理员需要先在小程序中将本轮设置为「准备开始」。在此之前，大屏会显示参与名单或候场提示。

Q: 为什么大屏没有变化？
A: 请确认活动管理员已准备当前轮次，且抽奖嘉宾已在小程序中执行开始或停止抽取操作；大屏会自动同步对应状态。

Q: 为什么不能开始本轮抽奖？
A: 请检查已加入且尚未中奖的在线参与人数是否不少于本轮奖品数量。

### 场景：让现场参与者通过大屏加入抽奖

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 全局管理员 | ✓ | 可作为活动参与者扫码加入。 |
| 租户管理员 | ✓ | 可作为活动参与者扫码加入。 |
| 群组主理人 | ✓ | 可作为活动参与者扫码加入。 |
| 群组管理员 | ✓ | 可作为活动参与者扫码加入。 |
| 普通用户 | ✓ | 可作为活动参与者扫码加入。 |

#### 操作入口

电脑浏览器 → 抽奖大屏首页 → 底部「邀请码」

#### 操作流程

1. 在 PC 大屏底部点击「邀请码」。
2. 大屏右侧会显示「扫码参与抽奖」二维码。
3. 现场参与者使用微信扫描该二维码，按小程序引导进入活动抽奖流程。
4. 参与者加入后，大屏参与名单会自动更新；候场状态下，新加入人员会出现在名单中。
5. 现场大屏操作人员在需要时可再次点击「邀请码」关闭或重新打开二维码。

#### 限制与约束

- 邀请码依赖本次大屏登录所对应的活动和抽奖信息；如果提示邀请码信息缺失，请退出大屏后重新扫码授权登录。
- 活动管理员在小程序中准备本轮后，大屏会自动关闭邀请码；电脑端仍可手动再次打开。
- 现场参与者需要在小程序中完成加入流程，才能进入抽奖候选名单。

#### 常见问题

Q: 为什么「邀请码」无法打开？
A: 当前大屏没有获得完整的活动或抽奖信息。请退出大屏，在电脑端重新生成二维码，并由本活动的活动管理员重新授权登录。

Q: 参与者扫码后为什么没有出现在大屏名单？
A: 请让参与者完成小程序中的加入流程，并确认网络正常；大屏会在参与者成功加入后自动更新。

### 场景：查看记录并调整大屏展示

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 全局管理员 | ✓（使用已授权的浏览器） | 可使用浏览器端展示工具。 |
| 租户管理员 | ✓（使用已授权的浏览器） | 可使用浏览器端展示工具。 |
| 群组主理人 | ✓（使用已授权的浏览器） | 可使用浏览器端展示工具。 |
| 群组管理员 | ✓（使用已授权的浏览器） | 可使用浏览器端展示工具。 |
| 普通用户 | ✓（经现场允许） | 浏览器端不单独校验小程序角色，应由现场负责人控制电脑操作权限。 |

#### 操作入口

电脑浏览器 → 抽奖大屏首页 → 底部工具栏

#### 操作流程

1. 点击「中奖记录」，查看各轮奖品、轮次状态、中奖人员和手机号后四位。
2. 点击声音按钮可打开或关闭现场背景音乐；首次打开大屏默认静音。
3. 点击「刷新」可重新加载当前抽奖状态和参与名单。
4. 点击「全屏」进入浏览器全屏展示；再次点击「退出」可返回普通展示模式。
5. 活动结束后点击「退出」，清除这台浏览器的大屏登录状态并回到登录页。

#### 限制与约束

- 浏览器不支持全屏或未授予全屏权限时，无法切换全屏。
- 全屏时会隐藏部分非必要操作，仅保留邀请码和退出全屏等现场展示所需功能。
- 登录信息失效后，大屏会回到登录页，需要本活动的活动管理员重新扫码授权。
- 背景音乐是否可播放受浏览器设备能力和声音设置影响。

#### 常见问题

Q: 为什么没有声音？
A: 大屏首次进入默认静音。请点击声音按钮开启；若浏览器不支持音频或阻止播放，请先与页面交互后再尝试开启。

Q: 为什么无法进入全屏？
A: 请检查浏览器是否允许网页全屏，并在浏览器提示时授权后重试。

Q: 为什么突然回到登录页？
A: 大屏登录信息已失效。请在电脑端重新生成二维码，并由本活动的活动管理员在小程序中重新扫码授权。

# 个人中心

## 概述

个人中心是喜多（HITO）小程序中用户管理个人信息、查看参与记录和管理社团活动的核心模块。通过个人中心，用户可以查看个人数据概览、编辑个人资料、浏览参与的活动时间线、管理所属社团和活动，以及查看个人二维码用于现场签到。

目标用户包括所有已登录的普通用户、社团管理员（CA）和社团主理人（CO），不同角色在个人中心中拥有不同的操作权限。

## 核心概念

- **打卡人身份（Persona）**：用户在喜多中的个人身份信息，包括昵称、头像、学号和手机号，用于在社团活动中标识用户。
- **管理社团**：用户作为社团主理人（CO）或社团管理员（CA）所管理的社团。
- **管理活动**：用户作为活动创建者所管理的活动。
- **参与时间线**：用户参与过的所有活动的按时间排列的记录。
- **社团角色**：用户在社团中的身份，包括群主（CO）、管理员（CA）和普通成员。
- **待绑定成员**：已添加到社团但尚未绑定微信用户的成员，可通过分享小程序给好友绑定。

## 操作指南

### 场景：查看个人首页

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✓ | 可查看个人数据概览和参与记录 |
| 社团管理员（CA） | ✓ | 可查看个人数据概览、管理社团和管理活动 |
| 社团主理人（CO） | ✓ | 可查看个人数据概览、管理社团和管理活动 |

#### 操作入口

社区首页 → 底部导航"我的" → 进入个人中心首页

#### 操作流程

1. 点击底部导航栏的"我的"，进入个人中心页面。
2. 页面顶部显示个人头像和昵称，点击昵称区域可进入编辑个人资料页面。
3. 查看数据概览卡片，包含三项统计数据：
   - **参与活动**：显示用户参与过的活动总数，点击可跳转到参与时间线。
   - **管理社团**：显示用户管理的社团数量，点击可进入"我已加入的社团"页面。
   - **组织活动**：显示用户创建的活动数量，点击可进入"我的活动"页面。
4. 下方依次显示"我管理的社团"、"我管理的活动"和"我参与的时间线"三个板块。
5. 点击页面左上角返回按钮可返回上一页，点击菜单按钮可展开更多选项。

#### 限制与约束

- 未登录用户点击数据概览卡片会弹出登录对话框，需先登录才能查看。
- 下拉刷新会同时刷新个人资料、管理社团、管理活动和参与时间线的数据。

#### 常见问题

Q: 个人首页显示"点击登录"怎么办？
A: 请点击昵称区域，在弹出的登录对话框中完成登录，登录后即可查看个人数据。

Q: 为什么管理社团板块不显示？
A: 如果您不是任何社团的主理人或管理员，该板块不会显示。

Q: 下拉刷新没有效果怎么办？
A: 请确保网络连接正常，下拉刷新会自动触发数据更新。

### 场景：编辑个人资料

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✓ | 可编辑自己的打卡人身份信息 |
| 社团管理员（CA） | ✓ | 可编辑自己的打卡人身份信息 |
| 社团主理人（CO） | ✓ | 可编辑自己的打卡人身份信息 |

#### 操作入口

个人中心首页 → 点击昵称区域 → 进入个人资料编辑页面

#### 操作流程

1. 在个人中心首页，点击头像下方的昵称区域。
2. 进入个人资料编辑页面，显示当前的头像、姓名、学号和联系电话。
3. 点击头像可更换头像，系统会调用微信的头像选择功能。
4. 修改姓名（必填项，最多18个字符）。
5. 修改学号（选填项，最多18个字符）。
6. 修改联系电话（选填项，需为11位手机号格式）。
7. 点击"确认修改"按钮保存修改。

#### 限制与约束

- 姓名为必填项，不能为空。
- 手机号格式需为11位数字，且以1开头。
- 未设置打卡人身份时，进入页面会弹出创建身份信息的对话框。
- 头像修改后需等待审核通过才能生效。

#### 常见问题

Q: 提示"请输入身份昵称"怎么办？
A: 请填写您的姓名后再次提交，姓名是必填项。

Q: 提示"请输入正确的电话"怎么办？
A: 请输入11位手机号码，且以1开头，例如：13800138000。

Q: 头像显示"审核中"或"不通过"怎么办？
A: 头像需要经过审核才能生效，请耐心等待审核结果。如审核不通过，请更换其他头像重新上传。

Q: 提示"资料未修改"怎么办？
A: 请确保至少修改了一项内容后再点击提交。

Q: 如何创建打卡人身份？
A: 首次进入个人资料编辑页面时，系统会自动弹出创建身份信息的对话框，填写必要信息后提交即可。

### 场景：我管理的社团

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✗ | 无管理社团，不显示此板块 |
| 社团管理员（CA） | ✓ | 可查看和进入管理的社团 |
| 社团主理人（CO） | ✓ | 可查看和进入管理的社团 |

#### 操作入口

个人中心首页 → 点击"管理社团"数字 → 或点击"全部社团"链接

#### 操作流程

1. 在个人中心首页，查看"我管理的社团"板块。
2. 社团列表以横向滚动卡片形式展示，最多显示5个。
3. 每个卡片显示社团头像、社团名称、角色标签（群主/管理员）和活动数量。
4. 点击任意社团卡片可进入该社团的详情页面。
5. 点击"全部社团"链接可进入"我已加入的社团"完整列表页面。

#### 限制与约束

- 仅显示用户作为主理人或管理员的社团。
- 最多显示5个管理中的社团。

#### 常见问题

Q: 为什么没有显示管理社团？
A: 请确认您是否为某个社团的主理人或管理员，只有拥有管理权限的社团才会在此显示。

Q: 点击社团卡片后跳转到哪里？
A: 会跳转到该社团的详情页面，您可以查看社团信息、成员和活动。

### 场景：我管理的活动

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✗ | 无管理活动，不显示此板块 |
| 社团管理员（CA） | ✓ | 可查看和进入管理的活动 |
| 社团主理人（CO） | ✓ | 可查看和进入管理的活动 |

#### 操作入口

个人中心首页 → 点击"组织活动"数字 → 或点击"全部活动"链接

#### 操作流程

1. 在个人中心首页，查看"我管理的活动"板块。
2. 活动列表以横向滚动卡片形式展示，最多显示5个。
3. 每个卡片显示活动状态标签、活动名称、时间、地点和参与数据（报名/参与人数）。
4. 活动状态标签根据当前时间自动判断：
   - **今日**：活动日期为当天，红色高亮显示。
   - **已打卡**：当前处于签到时间段内。
   - **已签退**：当前处于签退时间段内。
   - **报名中**：当前处于报名时间段内，红色高亮显示。
   - **即将开始**：活动日期在未来，灰色显示。
   - **已结束**：活动日期已过。
5. 点击任意活动卡片可进入该活动的详情页面。
6. 点击"全部活动"链接可进入"我的活动"完整列表页面。

#### 限制与约束

- 最多显示5个管理中的活动。
- 活动状态根据当前时间自动判断，无法手动修改。

#### 常见问题

Q: 为什么活动状态显示"今日"？
A: 当活动日期为今天时，系统会自动将状态标记为"今日"，并以红色高亮显示。

Q: 点击活动卡片后跳转到哪里？
A: 根据活动类型（打卡活动或普通活动），会跳转到对应的活动详情页面。

### 场景：查看我的参与时间线

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✓ | 可查看自己的参与时间线 |
| 社团管理员（CA） | ✓ | 可查看自己的参与时间线 |
| 社团主理人（CO） | ✓ | 可查看自己的参与时间线 |

#### 操作入口

个人中心首页 → 向下滚动至"我参与的活动"区域

#### 操作流程

1. 在个人中心首页，向下滚动至"我参与的活动"时间线区域。
2. 时间线按时间倒序展示用户参与过的所有活动。
3. 每条时间线记录显示活动标题、时间和参与人员头像。
4. 跨年时会显示年份分隔标记。
5. 向上滑动可加载更多历史记录。
6. 时间线底部显示"返回顶部"按钮，点击可快速回到页面顶部。

#### 限制与约束

- 每次加载20条记录。
- 支持下拉刷新和滚动加载更多。
- 无参与记录时显示空白状态。

#### 常见问题

Q: 时间线不显示内容怎么办？
A: 请确认您是否已登录且有参与活动的记录。如果没有参与记录，时间线区域将不显示。

Q: 如何查看更早的记录？
A: 向上滑动页面至底部，系统会自动加载更多历史记录。

### 场景：查看我已加入的社团

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✓ | 可查看和加入社团 |
| 社团管理员（CA） | ✓ | 可查看和加入社团 |
| 社团主理人（CO） | ✓ | 可查看和加入社团 |

#### 操作入口

个人中心首页 → 点击"管理社团"数字 → 进入"我的社团"页面

#### 操作流程

1. 在个人中心首页，点击"管理社团"数字或"全部社团"链接。
2. 进入"我的社团"页面，显示用户已加入的所有社团。
3. 页面顶部有搜索框，可输入关键字查找社团。
4. 右上角有"创建新社团"按钮，点击可进入创建社团流程。
5. 社团列表显示社团头像、名称、角色标签和活动数量。
6. 角色标签包括：
   - **群主**：红色标签，表示用户是该社团的主理人（CO）。
   - **管理员**：蓝色标签，表示用户是该社团的管理员（CA）。
   - 无标签：表示用户是普通成员。
7. 点击任意社团可进入该社团的详情页面。

#### 限制与约束

- 点击"创建新社团"会进入创建社团流程，创建成功后会自动刷新社团列表。
- 搜索支持按社团名称模糊匹配。

#### 常见问题

Q: 如何创建新社团？
A: 点击页面右上角的"创建新社团"按钮，按照提示填写社团名称、简称等信息后提交。

Q: 搜索不到想要的社团怎么办？
A: 请尝试使用不同的关键字搜索，或者确认该社团是否在当前社区内。

### 场景：查看我的活动

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✓ | 可查看参与的活动 |
| 社团管理员（CA） | ✓ | 可查看管理的和参与的活动 |
| 社团主理人（CO） | ✓ | 可查看管理的和参与的活动 |

#### 操作入口

个人中心首页 → 点击"组织活动"数字 → 进入"我的活动"页面

#### 操作流程

1. 在个人中心首页，点击"组织活动"数字或"全部活动"链接。
2. 进入"我的活动"页面，页面顶部有两个标签页：
   - **我管理的**：显示用户创建的活动。
   - **我参与的**：显示用户参与过的活动（包括报名、打卡和签退的活动）。
3. 默认显示"我管理的"标签页，可点击切换到"我参与的"标签页。

5. 点击任意活动可进入该活动的详情页面。
6. 无活动时显示空状态提示：
   - "我管理的"为空时显示"还没有创建的活动"。
   - "我参与的"为空时显示"还没有参与记录"。

#### 限制与约束

- 每次加载20条活动记录。
- 切换标签页时会重新加载数据。
- 列表底部显示"已加载全部"表示已无更多数据。

#### 常见问题

Q: 切换标签页后数据没有更新怎么办？
A: 请等待数据加载完成，如果网络不稳定可能导致加载延迟。

Q: 如何创建新活动？
A: 请进入您管理的社团详情页面，在活动管理区域创建新活动。

Q: 为什么"我参与的"标签页显示的活动比我实际参与的少？
A: 请确认活动是否已结束，只有已结束的活动才会显示在"我参与的"列表中。

### 场景：查看/编辑成员资料

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | 仅查看和编辑自己的 | 只能查看和修改自己的成员资料 |
| 社团管理员（CA） | 可查看和编辑普通成员的 | 可查看和修改社团内普通成员的资料，但不能修改主理人和其他管理员的资料 |
| 社团主理人（CO） | ✓ | 可查看和修改社团内所有成员的资料，包括设置管理员、VIP和删除成员 |

#### 操作入口

社团详情页 → 成员列表 → 点击成员 → 进入成员资料页面

#### 操作流程

**普通用户查看/编辑自己的资料：**

1. 进入社团详情页，点击成员列表中的自己。
2. 查看或修改以下信息：
   - **成员备注**：仅管理员可见的备注名（最多18个字符）。
   - **成员头衔**：在社团中的头衔（最多30个字符）。
   - **成员手机号**：手机号码（需为11位数字格式）。
3. 点击"确认修改"按钮保存修改。

**社团管理员（CA）编辑成员资料：**

1. 进入社团详情页，点击要编辑的成员。
2. 可修改该成员的备注名、头衔和手机号。
3. 对于待绑定成员，可选择"邀请用户绑定"或"合并到其他成员"。
4. 点击"确认修改"按钮保存修改。

**社团主理人（CO）管理成员：**

1. 进入社团详情页，点击要管理的成员。
2. 除编辑基本信息外，还可进行以下操作：
   - **设置管理员**：开启"群管理员"开关，将该成员设为管理员。
   - **设置VIP**：点击"会员"行的"设置"，开启VIP并设置到期日期。
   - **删除成员**：点击页面右上角删除按钮，输入成员备注确认后删除。

#### 限制与约束

- 成员备注为必填项。
- 手机号格式需为11位数字，且以1开头。
- 删除成员后，该成员将从社团所有事件中被移除，绑定用户将退出社团，且操作不可恢复。
- 删除成员时需要输入该成员的备注名进行二次确认。
- 只有社团主理人（CO）可以设置管理员。
- 社团管理员（CA）不能修改主理人和其他管理员的资料。

#### 常见问题

Q: 提示"请输入成员备注"怎么办？
A: 请填写成员备注后再次提交，备注是必填项。

Q: 提示"请输入正确的手机号"怎么办？
A: 请输入11位手机号码，且以1开头，例如：13800138000。

Q: 提示"资料未修改"怎么办？
A: 请确保至少修改了一项内容后再点击提交。

Q: 如何将待绑定成员合并到其他成员？
A: 在成员资料页面点击"合并到其他成员"，在弹出的成员列表中选择目标成员即可完成合并。

Q: 如何邀请待绑定成员绑定用户？
A: 在成员资料页面点击"邀请用户绑定"，系统会生成分享链接，可通过微信发送给好友。

Q: 删除成员时提示输入不正确怎么办？
A: 请输入该成员的完整备注名（与显示的备注名完全一致），才能完成删除确认。

### 场景：查看个人二维码

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✓ | 可查看个人二维码 |
| 社团管理员（CA） | ✓ | 可查看个人二维码 |
| 社团主理人（CO） | ✓ | 可查看个人二维码 |

#### 操作入口

个人中心首页 → 点击右上角二维码图标 → 弹出个人二维码对话框

#### 操作流程

1. 在个人中心首页，点击导航栏右侧的二维码图标。
2. 弹出个人二维码对话框，显示用户姓名、编码和二维码。
3. 二维码下方显示刷新倒计时进度条。
4. 二维码每30秒自动刷新一次，用于现场签到。
5. 二维码对话框支持关闭，点击右上角关闭按钮或点击遮罩层即可关闭。

#### 限制与约束

- 二维码需要已创建打卡人身份才能显示。
- 二维码每30秒自动刷新，过期后无法使用。
- 二维码用于现场签到场景，由管理人员扫描验证。

#### 常见问题

Q: 二维码显示"加载中..."怎么办？
A: 请稍等片刻，系统正在生成二维码，通常几秒内即可显示。

Q: 二维码显示不出来怎么办？
A: 请确认是否已创建打卡人身份。如果未创建，请先进入个人资料编辑页面创建身份信息。

Q: 二维码刷新后还能用吗？
A: 二维码每30秒自动刷新，刷新后的旧二维码将失效，请在有效时间内完成签到。

Q: 个人二维码和社团二维码有什么区别？
A: 个人二维码是您在喜多中的身份标识，可用于现场签到；社团二维码是加入社团的入口，两者用途不同。

### 场景：提交意见反馈

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✓ | 可提交意见反馈 |
| 社团管理员（CA） | ✓ | 可提交意见反馈 |
| 社团主理人（CO） | ✓ | 可提交意见反馈 |

#### 操作入口

个人中心首页 → 点击右上角菜单按钮 → 选择"意见反馈"

#### 操作流程

1. 在个人中心首页，点击右上角菜单按钮（三条横线图标）。
2. 在弹出的菜单中点击"意见反馈"。
3. 进入意见反馈页面，按以下步骤填写：
   - 选择反馈类型（功能建议、BUG反馈、其他）。
   - 填写反馈标题（最多30个字符）。
   - 填写反馈内容（最多1000个字符）。
   - 可选上传图片（最多9张）。
   - 选择是否允许回访（开启后需填写联系方式）。
   - 填写联系方式（微信号或联系电话）。
4. 点击"提交反馈"按钮提交。

#### 限制与约束

- 反馈类型为必选项。
- 反馈标题和内容为必填项。
- 开启回访开关后，联系方式为必填项。
- 每次最多上传9张图片，单张图片会自动压缩。

#### 常见问题

Q: 提示"请选择反馈类型"怎么办？
A: 请在反馈类型选择器中选择一种类型（功能建议、BUG反馈或其他）后再提交。

Q: 提示"请输入反馈标题"或"请输入反馈内容"怎么办？
A: 请填写标题和内容后再次提交，两者均为必填项。

Q: 提交后如何查看处理进度？
A: 目前暂不支持查看处理进度，我们会在收到反馈后尽快处理。如需紧急联系，可在页面顶部点击"直接联系管理员"。

Q: 如何直接联系管理员？
A: 在意见反馈页面顶部，点击"直接联系管理员"链接，系统会打开与管理员的私信对话窗口。

### 场景：使用更多菜单

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✓ | 可使用意见反馈、服务协议、隐私条款和重启小程序 |
| 社团管理员（CA） | ✓ | 同普通用户 |
| 社团主理人（CO） | ✓ | 同普通用户 |
| 全局管理员（GA） | ✓ | 额外可访问管理员菜单 |

#### 操作入口

个人中心首页 → 点击右上角菜单按钮 → 展开菜单列表

#### 操作流程

1. 在个人中心首页，点击右上角菜单按钮（三条横线图标）。
2. 弹出菜单列表，包含以下选项：
   - **意见反馈**：进入意见反馈页面（未登录时隐藏）。
   - **管理员菜单**：进入管理员后台（仅全局管理员可见，待审核事项有数字角标提示）。
   - **服务协议**：打开服务协议页面。
   - **隐私条款**：打开隐私条款页面。
   - **重启小程序**：重启小程序并返回首页。
   - **当前版本**：显示当前小程序版本号。
3. 点击任意菜单项可执行对应操作。
4. 点击菜单外部区域可关闭菜单。

#### 限制与约束

- 管理员菜单仅全局管理员（GA）可见。
- 未登录时，意见反馈菜单项隐藏。
- 菜单会自动关闭，点击外部区域或选择菜单项后菜单会收起。

#### 常见问题

Q: 菜单中没有"意见反馈"选项怎么办？
A: 请确认是否已登录，未登录时"意见反馈"选项会隐藏。

Q: 菜单中没有"管理员菜单"怎么办？
A: 管理员菜单仅对全局管理员（GA）可见，普通用户和社团管理员无法看到此选项。

Q: 点击"重启小程序"后会怎样？
A: 小程序会重新启动并返回到社区首页，当前页面状态会丢失。

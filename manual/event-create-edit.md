# 活动创建与编辑

## 概述

活动创建与编辑功能允许群组管理员在喜多平台上创建、修改和管理各类活动。支持创建普通活动和打卡活动两种类型，提供完整的活动信息配置、报名管理、签到打卡等能力。本功能面向群组主理人和管理员，帮助他们高效组织和管理线下活动。

## 核心概念

- **普通活动（CE）**：仅包含基本信息的活动，适用于不需要签到打卡的聚会、分享会等场景
- **打卡活动（CIE）**：包含报名和打卡功能的活动，适用于需要签到、签退的线下活动
- **报名设置**：配置活动报名时间、人数限制、收费等选项
- **打卡设置**：配置签到签退时间、定位打卡、打卡范围等选项
- **草稿**：保存但不发布的活动，可后续继续编辑发布
- **活动审核**：部分租户配置下，活动发布需要管理员审核

## 操作指南

### 场景：创建普通活动

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可在所属群组内创建活动 |
| 群组管理员 | ✓ | 可在所属群组内创建活动 |
| 租户管理员 | ✓ | 可在租户内任意群组创建活动 |
| 全局管理员 | ✓ | 可在任意群组创建活动 |

#### 操作入口

社区首页 → 选择群组 → 创建活动

#### 操作流程

1. 进入群组页面后，点击"创建活动"按钮
2. 选择活动类型为"普通活动"
3. 在"基本信息"页面填写以下内容：
   - 上传活动图片（最多12张），可选择第一张作为海报
   - 输入活动名称（必填）
   - 输入活动描述（可使用AI助手辅助生成）
   - 选择活动开始时间和结束时间（必填）
   - 选择活动地点（可选）
   - 开启或关闭评论区
4. 点击"立即发布"完成活动创建
5. 活动创建成功后跳转至活动详情页

#### 限制与约束

- 活动名称为必填项
- 活动开始时间不能晚于结束时间
- 如果选择了活动地点，必须输入地址信息
- 图片上传后会自动压缩处理

#### 常见问题

Q: 为什么无法创建活动？
A: 请检查是否已选择社团，以及是否填写了必填的活动名称和时间。

Q: 图片上传失败怎么办？
A: 请检查网络连接，或尝试重新上传。图片会自动压缩以优化显示效果。

Q: 可以使用AI生成活动描述吗？
A: 可以。在活动描述输入框点击AI助手图标，系统会根据图片和标题自动生成描述。

### 场景：创建打卡活动

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可在所属群组内创建打卡活动 |
| 群组管理员 | ✓ | 可在所属群组内创建打卡活动 |
| 租户管理员 | ✓ | 可在租户内任意群组创建打卡活动 |
| 全局管理员 | ✓ | 可在任意群组创建打卡活动 |

#### 操作入口

社区首页 → 选择群组 → 创建活动

#### 操作流程

1. 进入群组页面后，点击"创建活动"按钮
2. 选择活动类型为"打卡活动"
3. 在"基本信息"页面填写活动基本信息（同普通活动）
4. 点击"下一步"进入"报名打卡"页面
5. 配置报名设置：
   - 开启报名功能
   - 设置报名开始时间和结束时间
   - 设置人数限制（可选）
   - 上传活动群二维码和报名成功提示（可选）
   - 开启活动收费并设置金额（可选）
   - 设置活动问卷（可选）
6. 配置打卡设置：
   - 设置签到开始时间和结束时间
   - 选择活动地点
   - 开启位置打卡并设置打卡范围（可选）
   - 开启签退功能并设置签退时间（可选）
   - 绑定喜多打卡贴（可选）
   - 开启仅允许现场签到（可选）
7. 点击"立即发布"完成活动创建

#### 限制与约束

- 必须开启报名或打卡功能之一
- 报名开始时间不能晚于报名结束时间
- 签到开始时间不能晚于签到结束时间
- 如果开启位置打卡，必须选择活动地点
- 打卡范围默认200米，可调整为100-1000米
- 收费金额不能超过群组设定的最大收费金额
- 开启收费功能后，金额在活动发布后不可修改

#### 常见问题

Q: 为什么报名时间设置失败？
A: 请确保报名开始时间早于结束时间，且结束时间不晚于活动开始时间。

Q: 位置打卡是什么意思？
A: 开启后，用户必须在指定地点的打卡范围内才能完成签到，适用于需要现场参与的活动。

Q: 如何开启活动收费？
A: 在报名设置中开启"活动收费"开关，输入收费金额即可。注意发布后金额不可修改。

Q: 为什么无法开启收费功能？
A: 请联系群组管理员确认群组是否已开通收费权限，以及最大收费金额限制。

### 场景：编辑活动

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可编辑群组内任何活动 |
| 群组管理员 | 仅自己创建的 | 只能编辑自己创建的活动 |
| 租户管理员 | ✓ | 可编辑租户内任何活动 |
| 全局管理员 | ✓ | 可编辑任意活动 |

#### 操作入口

活动详情页 → 编辑活动

#### 操作流程

1. 进入需要编辑的活动详情页
2. 点击"编辑活动"按钮
3. 在"基本信息"页面修改活动信息
4. 点击"下一步"进入"报名打卡"页面（仅打卡活动）
5. 修改相关配置
6. 点击"保存修改"完成编辑

#### 限制与约束

- 编辑时不能切换所属社团
- 如果活动已发布且需要审核，修改后需要重新审核
- 已过期的报名/签到/签退时间不可修改
- 开启收费后，金额不可修改
- 草稿活动编辑后可直接发布

#### 常见问题

Q: 为什么编辑按钮不可用？
A: 可能原因：1) 你不是活动创建者且非群组主理人；2) 活动已删除。

Q: 修改活动后需要审核吗？
A: 取决于群组配置。如果群组开启了活动审核功能，已发布的活动修改后需要重新审核。

Q: 可以修改活动的时间吗？
A: 可以修改活动时间，但如果活动已开始报名或签到，相关时间可能无法修改。

### 场景：保存草稿

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可保存活动草稿 |
| 群组管理员 | ✓ | 可保存活动草稿 |
| 租户管理员 | ✓ | 可保存活动草稿 |
| 全局管理员 | ✓ | 可保存活动草稿 |

#### 操作入口

创建活动页面 → 存草稿

#### 操作流程

1. 在创建活动页面填写部分信息
2. 点击底部"存草稿"按钮
3. 草稿保存成功后返回上一页

#### 限制与约束

- 草稿不需要填写所有必填项
- 草稿不会对其他用户可见
- 草稿可后续继续编辑并发布

#### 常见问题

Q: 草稿和正式活动有什么区别？
A: 草稿仅对创建者可见，不会显示在活动列表中。发布后才会对其他用户可见。

Q: 如何查看已保存的草稿？
A: 在"我的活动"页面可以查看已保存的草稿。

### 场景：删除活动

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可删除群组内任何活动 |
| 群组管理员 | 仅自己创建的 | 只能删除自己创建的活动 |
| 租户管理员 | ✓ | 可删除租户内任何活动 |
| 全局管理员 | ✓ | 可删除任意活动 |

#### 操作入口

活动详情页 → 更多操作 → 删除活动

#### 操作流程

1. 进入需要删除的活动详情页
2. 点击右上角"更多操作"按钮
3. 选择"删除活动"
4. 确认删除操作

#### 限制与约束

- 已有付费订单的活动不可删除
- 删除操作不可撤销
- 删除活动会同时清除所有报名和签到记录

#### 常见问题

Q: 为什么无法删除活动？
A: 如果活动已有用户付费报名，则无法删除。请联系管理员处理。

Q: 删除活动后数据会丢失吗？
A: 是的，删除操作不可撤销，活动相关的所有数据将被清除。

### 场景：管理活动参与人

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 群组主理人 | ✓ | 可管理活动所有参与人 |
| 群组管理员 | ✓ | 可管理活动参与人 |
| 租户管理员 | ✓ | 可管理活动参与人 |
| 全局管理员 | ✓ | 可管理活动参与人 |

#### 操作入口

活动详情页 → 管理面板 → 参与人管理

#### 操作流程

1. 进入活动详情页
2. 点击"管理面板"
3. 选择"参与人管理"
4. 可执行以下操作：
   - 添加指定参与人
   - 移除参与人
   - 修改参与人描述

#### 限制与约束

- 只能添加群组内已有的成员
- 移除参与人不会影响已报名或已签到的用户

#### 常见问题

Q: 如何添加指定参与人？
A: 在参与人管理页面，点击"添加成员"按钮，选择要添加的群组成员即可。

Q: 移除参与人后，对方会收到通知吗？
A: 不会发送通知，但对方将无法在活动详情中看到自己。

Q: 可以修改参与人的角色吗？
A: 可以修改参与人的描述信息，但不能通过此功能修改其在群组中的角色。

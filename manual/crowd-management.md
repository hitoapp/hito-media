# 社团管理

## 概述

社团管理是喜多平台的核心模块，用于创建、运营和管理各类社群组织。每个社团拥有独立的时间轴、活动列表和成员体系，支持社团主理人、社团管理员和普通成员等多角色协作。

本模块服务于三类用户：租户管理员（TA）负责平台级社团管理和审核；社团主理人（CO）负责社团日常运营和成员管理；普通用户可浏览、关注社团并参与活动。

## 核心概念

- **社团（Crowd）**：平台中的社群组织单元，拥有独立的时间轴、活动和成员体系，隶属于某个租户（社区）。
- **社团主理人（CO）**：社团的创建者和拥有者，对社团拥有完整管理权限，包括成员管理、活动审核和社团设置。
- **社团管理员（CA）**：由主理人邀请或设置的管理人员，可执行大部分管理操作，但无法转让主理人或删除社团。
- **社团认证**：由租户管理员（TA）为社团开启的官方认证标识，已认证社团的新活动将在小程序首页展示。
- **社团申请（CR）**：普通用户提交的创建社团申请，需经 TA 审核通过后方可正式创建。
- **关注**：用户关注社团后，该社团的新活动将出现在个人首页的时间轴中。

## 操作指南

### 场景：用户申请创建社团

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✓ | 所有已登录用户均可提交社团创建申请 |
| 社团主理人 | ✓ | 同普通用户权限 |
| 社团管理员 | ✓ | 同普通用户权限 |
| 租户管理员 | ✗ | TA 不通过此入口创建，使用 TA 直接创建通道 |

#### 操作入口

社区首页 → 底部"我的"标签页 → 创建社团

#### 操作流程

1. 进入创建社团页面，填写社团名称（必填，最多 100 字）。
2. 可选填写社团简称（最多 30 字）、成立日期、顶部标语和底部标语。
3. 点击"创建新社团"按钮提交申请。
4. 若未关注喜多服务号，系统会弹窗提示关注后方可创建，点击"立即关注"跳转。
5. 提交成功后，页面上方会显示"你有 N 条正在审核中的社团申请"提示条，点击可查看申请状态。

#### 限制与约束

- 社团名称为必填项，不为空时才能提交。
- 创建前需关注喜多服务号（若租户启用了服务号功能），否则会被拒绝。
- 提交后进入待审核状态，需等待 TA 审核通过。
- 同一用户可同时提交多条申请，页面会显示待审核申请数量。

#### 常见问题

Q: 为什么提示"请先关注服务号"？
A: 创建社团前需要关注喜多服务号，以便接收审核结果等服务消息。请按弹窗引导完成关注。

Q: 提交后多久能审核通过？
A: 提交后进入待审核队列，具体审核时间取决于 TA 的处理速度。你可在"我的社团申请"中查看审核状态。

Q: 可以修改已提交的申请吗？
A: 不可以。如需修改信息，请提交新的申请或联系 TA 拒绝后重新提交。

### 场景：TA 直接创建社团

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 租户管理员 | ✓ | TA 可直接创建社团，无需审核流程 |
| 社团主理人 | ✗ | 无此权限 |
| 社团管理员 | ✗ | 无此权限 |
| 普通用户 | ✗ | 无此权限 |

#### 操作入口

管理后台 → 社团管理 → 创建社团

#### 操作流程

1. 进入创建社团页面，填写社团名称（必填）、社团简称、成立日期等基本信息。
2. 填写社团主理人的成员名称、学号、手机号和职位信息。
3. 点击提交，社团将直接创建成功。

#### 限制与约束

- 社团名称为必填项。
- TA 创建的社团直接生效，无需审核。

#### 常见问题

Q: TA 创建的社团和用户申请创建的有什么区别？
A: TA 创建的社团直接生效并分配主理人；用户申请创建的需经 TA 审核通过后才生效。

### 场景：TA 审核社团创建申请

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 租户管理员 | ✓ | TA 负责审核所有社团创建申请 |
| 社团主理人 | ✗ | 无此权限 |
| 社团管理员 | ✗ | 无此权限 |
| 普通用户 | ✗ | 无此权限 |

#### 操作入口

管理后台 → 社团申请

#### 操作流程

1. 进入社团申请列表页面，默认显示"待审核"标签页。
2. 可切换查看"待审核""已通过""已拒绝"三个状态的申请列表。
3. 点击某条申请，进入申请详情页，查看社团信息（名称、简称、成立日期、标语）和申请人信息（昵称、学号、手机号）。
4. 在待审核状态下，底部显示"拒绝"和"通过"两个按钮。
5. 点击"通过"后弹出确认弹窗，确认后社团正式创建，申请人自动成为社团主理人。
6. 点击"拒绝"后弹出确认弹窗，填写拒绝理由（默认为"管理员拒绝申请"），确认后申请状态变为已拒绝。

#### 限制与约束

- 仅待审核状态的申请可操作通过或拒绝。
- 通过后社团正式创建，不可撤销（需删除社团）。
- 列表支持下拉刷新和滚动加载更多。

#### 常见问题

Q: 审核通过后申请人的权限是什么？
A: 通过后申请人自动成为该社团的社团主理人（CO），拥有社团完整管理权限。

Q: 拒绝后申请人可以重新提交吗？
A: 可以。申请人可重新提交新的社团创建申请。

创建社团页面 → 点击"你有 N 条正在审核中的社团申请"提示条

#### 操作流程

2. 可切换查看"待审核""已通过""已拒绝"三个状态。
3. 点击某条申请可查看申请详情，包括社团基本信息、申请人信息和审核状态。

- 列表支持下拉刷新和滚动加载。

#### 常见问题

Q: 申请被拒绝了怎么办？
A: 被拒绝的申请无法修改，你可以重新提交新的社团创建申请。

### 场景：编辑社团资料（社团主理人/管理员）

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团主理人 | ✓ | 可编辑自己社团的所有资料 |
| 社团管理员 | ✓ | 可编辑社团资料 |
| 租户管理员 | ✓ | TA 通过管理后台编辑 |
| 普通用户 | ✗ | 非社团成员无法编辑 |

#### 操作入口

社团首页 → 点击导航栏社团头像区域 → 进入社团管理页面 → 点击"编辑基本信息"

#### 操作流程

1. 进入社团管理页面，查看当前社团信息（名称、简称、成立日期、标语、主理人等）。
2. 点击"编辑基本信息"进入编辑页面。
3. 修改社团名称（必填）、简称、成立日期、顶部标语、底部标语。
4. 点击"提交修改"按钮保存更改。
5. 保存成功后自动返回社团管理页面，信息已更新。

#### 限制与约束

- 社团名称为必填项。
- 社团简称最多 30 字，标语最多 100 字。
- 社团 Logo 和 Banner 的修改需通过社团资料页面单独操作。

#### 常见问题

Q: 为什么看不到"编辑基本信息"按钮？
A: 仅社团主理人（CO）和社团管理员（CA）可见此按钮。普通成员只能查看社团资料。

Q: 修改后多久生效？
A: 提交修改后立即生效。

### 场景：编辑社团资料（TA 视角）

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 租户管理员 | ✓ | TA 可编辑任意社团的资料 |
| 社团主理人 | ✗ | 通过自己的入口编辑 |
| 社团管理员 | ✗ | 通过自己的入口编辑 |
| 普通用户 | ✗ | 无此权限 |

#### 操作入口

管理后台 → 社团管理 → 选择社团 → 编辑基本信息

#### 操作流程

1. 在管理后台进入社团管理页面，查看社团详细信息和统计数据。
2. 点击"编辑基本信息"进入编辑页面。
3. 修改社团名称、简称、成立日期、顶部标语、底部标语。
4. 点击"提交修改"保存更改。

#### 限制与约束

- 社团名称为必填项。
- TA 的编辑权限高于 CO/CA，可管理任意社团。

#### 常见问题

Q: TA 和 CO 都能编辑社团资料，有什么区别？
A: 两者使用不同的接口但功能相同。TA 可以管理所有社团，CO 只能管理自己的社团。

### 场景：删除社团

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团主理人 | ✓ | 仅社团主理人可删除自己管理的社团 |
| 租户管理员 | ✓ | TA 可删除任意社团 |
| 社团管理员 | ✗ | 无删除权限 |
| 普通用户 | ✗ | 无此权限 |

#### 操作入口

社团首页 → 点击导航栏社团头像区域 → 进入社团管理页面 → 点击"删除社团"

#### 操作流程

1. 进入删除社团页面，显示社团名称和 ID。
2. 如果社团下还有活动，页面显示提示："删除社团前，需要先删除所有事件。左滑删除。"
3. 需要逐个左滑活动条目，点击"删除"按钮删除所有活动。
4. 所有活动删除完毕后，点击底部"删除社团"按钮。
5. 弹出确认弹窗，显示"此操作不可恢复！"警告，并要求输入社团名称以确认删除。
6. 输入正确的社团名称后，点击确认完成删除。

#### 限制与约束

- 必须先删除社团下的所有活动才能删除社团。
- 删除操作不可恢复，确认时需输入完整社团名称。
- 删除后社团及其所有数据将被永久移除。
- TA 和 CO 均可删除社团，但入口和操作方式不同。

#### 常见问题

Q: 为什么"删除社团"按钮是灰色的？
A: 社团下还有活动时，按钮置灰且显示"请先删除所有事件"。需要先删除所有活动后才能删除社团。

Q: 删除社团后可以恢复吗？
A: 不可以。删除操作不可恢复，所有社团数据将被永久移除。

### 场景：社团认证

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 租户管理员 | ✓ | 仅 TA 可开启或关闭社团认证 |
| 社团主理人 | ✗ | 无此权限 |
| 社团管理员 | ✗ | 无此权限 |
| 普通用户 | ✗ | 无此权限 |

#### 操作入口

管理后台 → 社团管理 → 选择社团 → 功能配置 → 官方认证

#### 操作流程

1. 进入社团管理页面，在"功能配置"区域找到"官方认证"卡片。
2. 认证开关旁显示当前状态："已认证"或"未认证"。
3. 点击开关切换认证状态，系统会即时保存。
4. 已认证社团的新活动将在小程序首页展示。

#### 限制与约束

- 仅 TA 可操作认证开关。
- 认证状态为布尔值（开/关），无中间状态。
- 切换后即时生效。

#### 常见问题

Q: 认证有什么作用？
A: 已认证社团的新活动将在小程序首页展示，提升社团曝光度。社团名称旁会显示认证标识。

Q: 社团主理人可以自己开启认证吗？
A: 不可以。认证由 TA 统一管理，社团主理人可联系 TA 申请认证。

### 场景：活动收费设置

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 租户管理员 | ✓ | 仅 TA 可设置活动收费上限 |
| 社团主理人 | ✗ | 无此权限 |
| 社团管理员 | ✗ | 无此权限 |
| 普通用户 | ✗ | 无此权限 |

#### 操作入口

管理后台 → 社团管理 → 选择社团 → 功能配置 → 活动收费

#### 操作流程

1. 进入社团管理页面，在"功能配置"区域找到"活动收费"卡片。
2. 显示当前收费上限金额和状态（未开启/已开启）。
3. 点击"修改"按钮进入编辑模式，输入新的收费上限金额（数字）。
4. 点击"提交"保存设置。
5. 设置为 0 表示不开启收费功能。

#### 限制与约束

- 仅 TA 可操作活动收费设置。
- 金额为数字类型，0 表示关闭收费功能。
- 非 0 时，该社团的活动可向每位参与者收取不超过该限额的费用。

#### 常见问题

Q: 设置收费后，社团主理人可以自行定价吗？
A: 社团主理人创建活动时可设置收费金额，但不能超过 TA 设置的上限。

Q: 如何关闭收费功能？
A: 将收费上限设置为 0 即可关闭。

### 场景：转让社团主理人

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社团主理人 | ✓ | 仅当前主理人可转让 |
| 社团管理员 | ✗ | 无此权限 |
| 租户管理员 | ✗ | 无此权限（通过 CO 接口） |
| 普通用户 | ✗ | 无此权限 |

#### 操作入口

社团首页 → 点击导航栏社团头像区域 → 进入社团管理页面 → 邀请管理员（转让入口）

#### 操作流程

1. 社团主理人进入社团管理页面。
2. 选择"邀请管理员"或通过成员管理找到目标成员。
3. 发起转让操作，选择目标社团成员。
4. 确认转让后，目标成员成为新的社团主理人，原主理人降为普通成员。

#### 限制与约束

- 仅当前社团主理人可执行转让操作。
- 目标用户必须是社团成员。
- 转让后原主理人将失去主理人权限。
- 一个社团同时只能有一个主理人。

#### 常见问题

Q: 转让后我还能管理社团吗？
A: 转让后你将变为普通成员，不再拥有主理人权限。如需恢复，需由新主理人重新设置。

Q: 可以转让给非社团成员吗？
A: 不可以。目标用户必须先加入社团成为成员。

### 场景：关注/取关社团

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 普通用户 | ✓ | 所有用户均可关注或取关社团 |
| 社团主理人 | ✓ | 同普通用户权限 |
| 社团管理员 | ✓ | 同普通用户权限 |
| 租户管理员 | ✓ | 同普通用户权限 |

#### 操作入口

社团首页 → 社团名称下方的关注按钮

#### 操作流程

1. 进入社团首页，在社团名称下方找到关注按钮（"关注"或"取消关注"）。
2. 点击"关注"，弹出确认弹窗说明关注后社团新活动将出现在个人首页，确认后关注成功。
3. 已关注状态下，按钮变为"取消关注"，点击后弹出确认弹窗，确认后取消关注。
4. 关注按钮旁有问号图标，点击可查看关注说明弹窗。

#### 限制与约束

- 关注和取关均为 toggle 操作，重复调用会切换状态。
- 关注后社团新活动将出现在个人首页时间轴。
- 取消关注后社团新活动不再出现在个人首页。

#### 常见问题

Q: 关注社团有什么好处？
A: 关注社团后，该社团发布的新活动将自动出现在你的个人首页时间轴中，方便及时参与。

Q: 关注后会被社团成员看到吗？
A: 关注操作不会通知社团成员，但社团首页会显示关注人数统计。

Q: 非社团成员可以关注吗？
A: 可以。关注和加入社团是两个独立操作，关注不影响加入。

#### 角色权限

#### 常见问题

Q: 为什么有些社团有认证标识？
A: 认证标识由 TA 为社团开启，表示该社团为官方认证社团，其新活动将在首页优先展示。

Q: 如何找到我感兴趣的社团？
A: 可通过首页推荐区域浏览，或使用搜索功能按名称查找社团。

# 活动审核流程

## 概述

活动审核流程是喜多平台为保障社区内容质量而设计的管理机制。当社区管理员开启「活动需要审核」配置后，所有社团创建或修改的活动均需经过审核通过后才能正式发布。

本功能主要服务于社区管理员（TA），用于统一管理社区内所有活动的审核工作；同时支持社团主理人（CO）和社团管理员（CA）查看自己提交的审核记录及审核进度。

## 核心概念

- **审核状态**：待审核（审核中）、已通过（审核通过）、已拒绝（审核未通过）
- **审核阶段**：创建活动（新建活动提交审核）、编辑活动（修改已发布活动提交审核）
- **活动审核开关**：社区级配置，控制该社区下所有活动是否需要审核
- **审核待办**：社区管理员审核任务列表，按时间倒序展示

## 操作指南

### 场景：TA 审核活动（列表 → 详情 → 通过/拒绝）

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社区管理员（TA） | ✓ | 拥有全部审核权限，可审核所有活动 |
| 社团主理人（CO） | ✗ | 仅可查看，不可执行审核操作 |
| 社团管理员（CA） | ✗ | 仅可查看，不可执行审核操作 |

#### 操作入口

管理后台首页 → 左上角菜单 → 活动审核

#### 操作流程

1. 进入审核列表页，页面默认显示「全部」状态的审核记录
2. 可通过顶部标签页切换查看不同状态：全部、待审核、已通过、已拒绝
3. 点击任意一条审核记录，进入审核详情页
4. 在详情页查看活动信息：
   - 审核信息区：显示申请人、申请时间、审核状态
   - 活动内容区：显示活动标题、描述、海报、时间、地点等详细信息
   - 如为修改审核，会同时展示修改前后的对比内容
5. 确认审核结果：
   - 通过审核：点击底部「通过审核」按钮
   - 拒绝审核：点击底部「拒绝」按钮，在弹窗中输入拒绝原因后确认
6. 审核完成后自动返回列表页，已审核的记录将从待审核列表移除

#### 限制与约束

- 审核操作仅支持 TA 角色执行
- 拒绝审核时必须填写拒绝原因（最多 500 字）
- 同一活动同一时间只能有一个待审核的修改请求
- 审核通过后，活动状态变更为已发布；拒绝后，活动保持原状态

#### 常见问题

Q: 审核详情页无法点击「通过审核」或「拒绝」按钮？
A: 请确认您当前登录账号为社区管理员（TA）身份，且该活动处于「待审核」状态。

Q: 审核列表显示「暂无数据」？
A: 请确认当前社区已开启「活动需要审核」配置，且有社团提交了活动审核申请。

Q: 拒绝审核时提示「请填写拒绝原因」？
A: 拒绝审核必须填写原因，请在弹窗的文本框中输入拒绝理由后再次提交。

### 场景：CA/CO 查看自己提交的审核记录

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社区管理员（TA） | ✓ | 可查看全租户所有审核记录 |
| 社团主理人（CO） | ✓ | 可查看自己群组内所有审核记录，或仅查看自己提交的 |
| 社团管理员（CA） | ✓ | 仅可查看自己创建的活动审核记录 |

#### 操作入口

群组首页 → 左上角菜单 → 活动审核

#### 操作流程

1. 进入审核列表页，页面默认显示当前群组的审核记录
2. **对于社团主理人（CO）**：
   - 页面顶部显示「仅显示我提交的」开关
   - 开启开关：仅显示自己提交的审核记录
   - 关闭开关：显示该群组全部审核记录
3. **对于社团管理员（CA）**：
   - 仅显示自己创建的活动审核记录，无筛选开关
4. 可通过顶部标签页切换查看不同状态：全部、待审核、已通过、已拒绝
5. 点击任意一条审核记录，进入详情页查看审核详情
6. 在详情页可查看：
   - 审核状态及审核人信息（如已审核）
   - 活动修改前后的内容对比
   - 底部显示「查看活动」按钮（如活动已发布）

#### 限制与约束

- CA 角色仅能查看自己创建的活动审核记录
- CO 角色可查看群组内所有成员提交的审核记录
- 详情页仅显示审核信息，不可执行审核操作（通过/拒绝按钮仅 TA 可见）

#### 常见问题

Q: 为什么看不到某些审核记录？
A: 请确认您当前的身份角色：
   - 社团管理员（CA）：仅能看到自己创建的活动
   - 社团主理人（CO）：可看到群组内所有记录

Q: 审核详情页显示「活动审核中」弹窗提示？
A: 这是系统提示，告知您活动修改需等待管理员审核通过后生效，审核结果将通过服务号消息发送。

Q: 点击「查看活动」提示「无法查看活动详情」？
A: 如果活动处于待审核或已拒绝状态，暂时无法查看详情，需等待审核通过后查看。

### 场景：审核状态流转说明

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 所有角色 | - | 此场景为状态流转说明，无权限差异 |

#### 操作入口

此为系统自动流转说明，无需手动操作

#### 操作流程

1. **创建活动提交审核**：
   - 社团管理员（CA）创建活动 → 系统自动提交审核 → 进入「待审核」状态
2. **修改活动提交审核**：
   - 社团管理员（CA）修改已发布活动 → 系统自动提交审核 → 进入「待审核」状态
3. **审核通过**：
   - 社区管理员（TA）点击「通过审核」 → 状态变更为「已通过」
   - 创建活动：活动正式发布，可在社群中展示
   - 修改活动：修改内容生效，活动更新
4. **审核拒绝**：
   - 社区管理员（TA）点击「拒绝」并填写原因 → 状态变更为「已拒绝」
   - 活动保持原状态，修改内容不生效
   - 申请人可查看拒绝原因并重新修改后再次提交

#### 限制与约束

- 审核状态变更后不可回退
- 审核结果通过服务号消息通知申请人
- 已通过的活动再次修改会重新进入审核流程

#### 常见问题

Q: 活动提交审核后多久能通过？
A: 审核时间取决于社区管理员（TA）的工作安排，通常在 1-3 个工作日内完成审核。

Q: 审核被拒绝后如何处理？
A: 请查看拒绝原因，根据反馈修改活动内容后重新提交审核。在审核详情页点击「查看活动」可跳转至活动编辑页面。

Q: 审核通过后修改内容没有生效？
A: 请确认网络连接正常，尝试刷新页面。如问题持续，请联系社区管理员确认。

### 场景：审核开关配置（eventNeedAudit）

#### 角色权限

| 角色 | 可否执行本操作 | 说明 |
|------|---------------|------|
| 社区管理员（TA） | ✓ | 可修改社区级审核配置 |
| 社团主理人（CO） | ✗ | 无权限修改 |
| 社团管理员（CA） | ✗ | 无权限修改 |

#### 操作入口

管理后台首页 → 左上角菜单 → 社区设置 → 小程序配置

#### 操作流程

1. 进入社区设置页面，找到「小程序配置」选项
2. 查看当前「活动需要审核」开关状态：
   - 开启状态：所有社团创建或修改活动均需审核
   - 关闭状态：活动创建或修改无需审核，直接发布
3. 点击开关切换状态：
   - 开启 → 关闭：后续活动不再需要审核
   - 关闭 → 开启：后续活动需要审核
4. 保存配置后立即生效

#### 限制与约束

- 仅社区管理员（TA）有权限修改此配置
- 配置变更仅影响后续活动，已提交的审核不受影响
- 关闭审核开关后，已进入审核流程的活动仍需完成审核

#### 常见问题

Q: 关闭审核开关后，之前提交的审核记录会怎样？
A: 已提交的审核记录不受影响，仍需完成审核流程。

Q: 开启审核开关后，之前发布的活动需要重新审核吗？
A: 不需要。开启开关仅影响后续新建或修改的活动，已发布的活动不受影响。

Q: 为什么修改了配置但没有生效？
A: 请确认操作账号为社区管理员（TA）身份，且配置已保存成功。如问题持续，请尝试刷新页面或重新登录。
